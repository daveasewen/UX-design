Decision control 3 — the rung's name

What do we call it?

Two spellings. Pick one, or come back to it — export works either way.

rag.<hue>-text

Names the JOB (this value's use is text). Matches the pattern's own description throughout this page.

rag.<hue>-ink

Names the ROLE, matching the existing ink vocabulary elsewhere in the store.

Precedent this has form: text.on-information was minted at s131-D1 as a severity-specific ink slot — verbatim from the token file: "MINTED as the severity-specific info ink slot so themes with a DARK info fill (legacy #305A85) can reverse text/marks to white without touching on-light (which warning must keep dark)." Minting a dedicated ink/text rung for a specific need, without touching the base value, is already an established move in this store — this would be the second.
