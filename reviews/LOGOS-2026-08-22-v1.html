Three lockups, each in Colour and Monotone, each in an On light and an On dark treatment — the on-dark artwork is the reverse cut, drawn for dark surfaces. Twelve files in all, in knowledge/assets/logos/. Every fill in every file is hardcoded, so no logo follows a theme: each tile below is fixed to the ground its artwork was drawn for, in all four themes and in both modes. The page chrome follows the theme; the tiles deliberately do not.

Masterbrand with identifier

On light — tile ground #FFFFFF
On dark — tile ground #1A1A1A
⚠ Measured, not fixed — the two ON-DARK identifier exports carry no identifier label.

Both dark files are the plain masterbrand artwork on a 795-unit viewBox: the label paths are absent, so 480 units (60% of the box) render empty. Counting path starts whose x exceeds the masterbrand’s own 315-unit width (the label is a single compound path) — light-colour 1 · light-mono 1 · dark-colour 0 · dark-mono 0. masterbrand-identifier-dark-colour.svg is byte-identical to masterbrand-dark-colour.svg apart from the viewBox width and one rounding digit. Logged as ds-045 in knowledge/_DS-IMPROVEMENTS.md; re-exporting is the fix and it is not this page’s to make.

What the record says

Everything in this list is quoted or paraphrased from knowledge/guidelines/logos.md. No usage policy is authored here.

  • The detailed logo standard — usage, structure, behaviours, placement, clear space, minimum sizes — lives on create.hsbc (Foundations and identity › Logos). The Figma page is a sticker sheet of artwork.
  • Source: HSBC Common Toolkit (MCP), “Gaps and edits” branch, Foundations › Logos page (node 29:1009). Exported 2026-06-17 by knowledge/assets/logos/_export-logos.py.
  • The identifier label is set in Univers Next Light.
  • No design tokens. The Figma logos page carries none, and none of the twelve files references one.
  • Per the icons sourcing rule, these exports are internal prototype assets. For production and dev handoff, source official logo artwork from create.hsbc / the UI Centre.
  • The crescent is an Apollo-only brand mark and is not part of this set.

Open to Dave — surfaced, not ruled

  • The two on-dark identifier exports carry no identifier label (measured above). Re-export or retire — a policy call, not this page’s.
  • The monotone on-light artwork fills with pure black, which is not the project ink (#1A1A1A, blackest-never-pure-black). It is brand artwork, so it is surfaced, never swapped.
  • The hexagon red is #DB0011 — the brand primitive, not the two-red law’s UI ink. Stated so the difference is not read as a defect.
