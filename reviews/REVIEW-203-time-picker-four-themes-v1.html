Time picker

The gated Time picker. It deliberately does not use a calendar grid — time has no calendar — so it borrows the Dropdown listbox language instead: 44px options, tabular figures so the column aligns, selection carried by weight plus a neutral tick.

Read this first. This component was not built in #203. It was built on 2026-07-22 (Phase-2 wave 2) and has been gated ever since. The Wave-3 brief carried it as a P1 gap from the 2026-07-14 itinerary; that status column is stale. Nothing in the gated snippet was edited. This page exists because the component has never been put in front of your eye across all four themes at once — only through the showroom's one-at-a-time theme switcher.

PROPOSED #203, Dave's eye owed — nothing below is ruled:

  • The Wave-3 brief asked Lane B to share one calendar-grid grammar across all three. Time picker cannot and should not — it is a listbox. Its shared grammar with the other two is the field anatomy (Input-fields box + tail button), which it already consumes. Proposal: record that the calendar grammar spans two of three, by design.
  • Same 9 type-composite violations as the other two.
  • Selection is weight + tick, never colour alone — deliberate, given red/yellow instability. Worth your eye in Supercharge dark where the tick sits on a warm neutral.

Static page: “today” is pinned to 22 July 2026 so the today-ring is visible in every pane. In the live snippet the ring follows the real date.
