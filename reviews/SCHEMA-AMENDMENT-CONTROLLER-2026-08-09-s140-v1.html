D1 — shape of props[].binds DAVE'S

A — single string

One spine token name per prop. Simplest; a prop binding two tokens has nowhere to put the second. 
"binds": "--chart-cat-1"

B — string or array ★ RECOMMENDED

String for the common case, array where a prop's values range over several spine tokens. Strictly generalises A; invents no new vocabulary. 
"binds": "--chart-cat-1"
"binds": ["--btn-bg", "--btn-ink"]

C — intent map

Names each binding's intent. Most expressive, but duplicates the component-level tokens field's job and no consumer needs the intent axis yet. 
"binds": { "fill": "--chart-cat-1", "ink": "--chart-ink" }
