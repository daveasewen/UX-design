2 · The two contenders — this is the real design question

Both fix the boundary. They differ on one thing: do the light fills match the dark ones, or are they optimised per-mode? Amber is the same in both — its identity is lightness, so on white it can't hold a boundary without a border (going darker makes it brown, which R-D3 already rejected). Everything gets the R-D11 extra vertical padding.

Option 0 · Per-mode optimised — restore the R-D4 light values MY STEER

Green + blue go back to the values already built and ruled for the white page (R-D4: #2B7E4F / #306EC6, white text) — the dark-ramp re-seated them lighter for the dark page only. Deeper fills + white text hold their boundary cleanly and read as one confident family. Amber keeps #F0B13A + its ruled glyph #C58900 as a hairline border.

The decision — which light-mode fill set, and is the amber caveat acceptable

Option 0 (per-mode): darker green/blue + white text (restore R-D4); solid, emphatic; two values per hue.

Option B (continuity): same hues as dark + borders; lighter, related across modes; one value per hue.

Amber, either way: pale fill + border + black text. Accept that watch leans on its label/border rather than out-shouting the states on white? (The alternative — a louder watch — means a darker amber, i.e. brown, which R-D3 barred.)

My steer: Option 0. The green/blue values were already ruled for white; restoring them is the smallest true correction, and solid fills carry a status column better than bordered pale ones. Borders can still be added to Option 0 later if you want extra definition. If mode-to-mode continuity matters more than emphasis, Option B is the pick.

Pin a set (0 / B / neither), and say whether the amber caveat is acceptable. Then I reconcile the two modes into the token table and it's ready for the Sonnet promotion behind the blast-radius gate.
