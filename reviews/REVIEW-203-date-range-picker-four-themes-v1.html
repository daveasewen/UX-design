Date-range picker

The gated Date-range picker. The range demo shows 6–14 July 2026: endpoints are the ink knockout, the run between them carries a tint. The tint is deliberately never the only channel — endpoints change weight and every cell carries aria-selected.

Read this first. This component was not built in #203. It was built on 2026-07-22 (Phase-2 wave 2) and has been gated ever since. The Wave-3 brief carried it as a P1 gap from the 2026-07-14 itinerary; that status column is stale. Nothing in the gated snippet was edited. This page exists because the component has never been put in front of your eye across all four themes at once — only through the showroom's one-at-a-time theme switcher.

PROPOSED #203, Dave's eye owed — nothing below is ruled:

  • The calendar grammar is duplicated by copy, not shared: 19 of 20 grid/nav/day rules are byte-identical between Date-picker (.dp-*) and Date-range-picker (.dr-*), differing only in a code comment. The meta already declares $consumes: Date-picker (panel + grid + keyboard model — change it there), but nothing enforces it. Proposal: promote the calendar grid to a shared partial so the two cannot drift. This is a component-promotion question — yours alone.
  • Same 9 type-composite violations as Date picker.
  • The in-range tint uses form/background/hover. In dark themes that tint is subtle; check whether the range run reads for you, particularly in Legacy and Supercharge dark.

Static page: “today” is pinned to 22 July 2026 so the today-ring is visible in every pane. In the live snippet the ring follows the real date.
