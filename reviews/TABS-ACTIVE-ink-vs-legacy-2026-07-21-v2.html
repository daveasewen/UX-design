The snap, explained

Rather than an arbitrary opacity:.62, the inactive-tab opacity is solved so that ink composited over the surface lands exactly on a named mono rung: α = (rung − surface) / (ink − surface). So the inactive label is a real token colour, not a blend artifact — and it differs per mode because the surface and ink differ. Move the slider to pick the rung; the opacity is derived and shown above.

  • Default = mono/7 light · mono/9 dark (≈6:1, both AA-legible). Slider stays on rung 7 → light shows mono/7, dark shows mono/9 automatically at the matched contrast.
  • Legacy is untouched: full-strength inactive labels, red bar + red badge. Only differentiator is the bar — eyeball whether that reads for you.
  • Below mono/8 the inactive label drops under 4.5:1 — flagged in the readout if you go quieter.
