Where this starts

AI can build an interface
in seconds.

That's the exciting part. The catch: left to itself, it drifts — off brand, off accessibility, off everything we've agreed matters. Fast and wrong is still wrong.

So we asked: what would it take to make AI a proper design colleague — one that knows our system, and remembers what it learned yesterday?

02 / 12

Two answers, one project

Apollo

The engine. It teaches the AI our design system — so what it builds is on-brand and accessible from the start.

Memento

The memory. It lets the AI keep what it learns — so every session builds on the last instead of starting from zero.

One makes the work right. The other makes it cumulative.

The point of it

The build is automated.
The craft is the point.

The machine assembles what's already known. You're freed for what isn't — new patterns, journeys, judgment, taste. AI doesn't replace the craft. It clears the ground for it.

06 / 12

Memento

An AI wakes up every morning
with no memory of yesterday.

Every session is the first day on the job. The context is gone, the decisions are gone, the half-finished thought is gone.

Memento is named for the film. Leonard can't form new memories — but he survives by a system: tattoos for what must never be wrong, Polaroids for the day's working notes, and a hard discipline about whose handwriting to trust.

07 / 12

Memento · how it remembers

Three kinds of true.

What a session learns is written home before it ends — but layered by how firmly it's known. Nothing gets flattened into one pile of notes.

A passing idea

Floated

Worth keeping, not yet trusted. A Polaroid — today's working note.

A repeated observation

Standing

It's held up more than once. Carried forward with its evidence attached.

A settled decision

Canon

Ruled, permanent, never quietly reworded. The tattoo.

The real enemy was never forgetting. It's the confident false inscription — the wrong thing written in permanent ink, read tomorrow as truth. Most of Memento's engineering goes into preventing exactly that.

08 / 12

Memento · where it is today

Built inside a live project,
not designed in the abstract.

Every rule in it exists because a session once went wrong without it. It runs Apollo's own build, daily — the design system you just saw is what it remembers with. Tested first, written down only when it survived.

Now: a working engine

Designers experimenting with a skill pack in their own tools; a growing reviewed component library; standards enforced, not hoped for.

Next: one design brain

A richer knowledge base as the shared source of truth, powering many modes of creation — from strict production assembly to genuinely new patterns.

Memento · now → next

Now: a proven discipline

A memory system battle-tested on one demanding project — keeping the record, pacing the work, orienting every session.

Next: memory for any team's AI

The same discipline, packaged so any project's assistant can keep what it learns — and prove its own record honest.
