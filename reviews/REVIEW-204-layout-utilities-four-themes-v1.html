Grid / stack utilities

Itinerary row 82, PROPOSED #204 — your eye owed. Verified absent first-hand, and confirmed against the itinerary’s own warning: this is not row 51’s Data-grid. A Data-grid’s columns mean something — they are fields. A layout grid’s columns mean nothing — they are space.

The gap is measured, not asserted — and it is bigger than it looks. The responsive-grid recipe these utilities would own is already hand-written in thirteen gated snippets, and they disagree: four different track floors (180 / 240 / 300), four different gaps, two different max-widths, and two different keywords — auto-fill in eleven, auto-fit in Cards twice. That last one is a real behavioural difference, not a stylistic one, and nothing in the repo records it as a decision. Nothing here reconciles them: picking one set is a ruling, and rulings are yours.

Two things the token store cannot reach, both declared. The whole spacing ramp lives in spacing.json, which the snippet gate’s resolver does not load — so the one component whose entire subject is spacing is the one component that cannot bind its own values through the gate. And a breakpoint token can never be bound in CSS at all: a media query cannot read a custom property. Every literal value below carries its token path in a comment so a human can audit what the machine currently cannot.

One primitive was deliberately not built. The classic name for “side by side until they run out of room, then stacked” is a switcher — and in this system “switch” is ruled vocabulary meaning the thumb of a toggle. Building it under that name would manufacture exactly the collision this component opens by warning about. Declared, not quietly omitted; the name would be yours.

Look at the split. The same markup appears twice and the second copy has already collapsed — because the frame around it is 420px wide, on a screen that is nowhere near narrow. A viewport query cannot see that; a container query can. That single case is the argument for which kind of query a primitive should use, and it is unruled.
