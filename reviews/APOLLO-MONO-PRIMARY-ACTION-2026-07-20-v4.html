Apollo Mono — the primary-action token · live editor

Mono is monochrome UI — colour only in dataviz, RAG, status — so the primary carries no red. Hover it, press it. Hover runs on opacity (the fill fades over the page) and we also store the opaque colour equivalent as a token for portability — both, operationally different. Every control is locked to the mono ramp and clamped so only AA-passing selections are possible.
