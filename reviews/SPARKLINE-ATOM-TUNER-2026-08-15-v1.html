What this file does and does not settle

NOT a ruling. Nothing here is inscribed. The compile button produces text for you to paste; it writes no file. The mock card is scenery — the trend card is FLOATED, not ruled (s182-D2, your words: "might be a partially built trend card with option, I haven't decided yet").

Colour candidates are the whole existing set, not a shortlist. Read from knowledge/canon/canon.css: the 5-step series ramp, the 5-step high-contrast ramp, the four data-vis hue ramps (blue / purple / pink / orange / green), the four delta tokens, and the greys + mono ink. Greys are surfaced, not swapped. The current value --data-series-1 is in the list and marked CURRENT — no pre-selection away from it.

The two-red law (s151-D1) and the mono error ink (s149-D1) are untouched and deliberately ABSENT from this palette. #DA1A00 / #F6604C are error inks with a background-keyed law of their own; offering them as a data stroke would put a second red in play. --data-delta-loss IS offered because it is a data token — but it carries a "reads as loss" flag on the chip, because a red trend line will be read semantically.

FOUR THEMES — measured, not assumed. I checked whether mono / legacy / console / supercharge fork these colours: knowledge/tokens/themes/apollo-legacy.overrides.json, apollo-console.overrides.json and apollo-supercharge.overrides.json contain zero data/series* overrides — grepped, all three empty. So all four themes inherit the same ramp, and light/dark is the COMPLETE picture for a stroke pick, not a v1 shortcut. DECLARED GAP: the three theme files were checked for the SERIES tokens only. If a theme forks the PAGE surface the stroke sits on, the contrast numbers on the chips would move — that is not measured here.

Scaling, as built: the dial is continuous on width (responsive, exactly the atom's .dv-fit-on behaviour). Height is derived at the atom's reviewed 340×64 proportion and then snapped: Math.round(h/4)*4. The headline numeral scales with the atom and snaps to the nearest rung of the real type ramp (.t-cm-figure-1/2/4/3/5/6 = 52 / 40 / 32 / 24 / 16 / 14), reported by class name — the countdown-timer mechanism you named. DECLARED GAP: the numeral rung is a proportional pairing I chose for the tuner so you can see the two scale together; the figure/spark size pairing is not itself ruled and does not become one by living here.
