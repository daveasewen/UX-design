How to read this

P1 = reliability-critical (build first — removes the reason the engine invents). P2 = common. P3 = nice-to-have. Status: Gated already reviewed · Partial exists, needs a variant · Gap to build. “Mine from” names the reference library to review each gap against.

Layer 1 = base components (~96). Layer 2 = shells, templates and lock-ups (~28) that compose from the bases; with per-component variant matrices these multiply into the 200–300 catalogue. Every gap runs the existing gated pipeline (snippet → meta → gate → .cn-*) — a content build, not new infrastructure. Indicative counts for shaping the plan, not a commitment.
