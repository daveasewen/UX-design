In-context component controls — the μX concept

Selecting a component surfaces its own controls in place (no sidebar). Now there are two grab bars: one moves the component within the layout stack, one moves its controls. Movement is DOM-flow, not absolute — the component snaps between slots; arrow keys ↑ ↓ reorder it in the stack.

Try it: drag the component grab bar to reorder it among the blocks · press ↑ / ↓ to move it a slot · drag the controls grab bar — the panel snaps to dock below or beside the component · Size / Style / Max time / Theme update live.
