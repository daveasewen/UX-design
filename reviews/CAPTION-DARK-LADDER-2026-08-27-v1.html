The dark caption ground — a ladder

Dave has given the direction and not the value. This page draws the same capsule card once per candidate ground, in console dark, so the value can be pointed at rather than argued about.

Every rung is the same card: same photograph, same markup, same stylesheet, same dials. The only thing that changes from one rung to the next is a single value substituted into the capsule’s caption-ground slot. Light is shown once, small, for reference — nothing on this ladder changes it.

Nothing on this page is enacted. No rule, no manifest, no generator and no ruling record has been changed to build it.

Where it stands

“The caption in dark mode is too dark”

“looks good except the caption in dark mode is too dark in capsule mode.”

Dave, 2026-08-27, on the console chord — capsule, gallery.

Light first, so it is on the record that light is fine

Both light capsules draw all the way round today. The ladder below does not touch either of them — it is a dark-mode value, and light keeps what it has.

The lightest-grey light capsule is the anchor this page keeps returning to. Its caption ground sits 1.14:1 from the page, ΔL* 5.20. That is the separation Dave has looked at and not objected to, so it is the one honest reference point for “enough” that exists anywhere in the system.

How to read a rung

Four numbers, and only one of them has a rule behind it

  • Caption ground and page ground — the two colours the eye is being asked to tell apart. Both are read off the rendered card, not off the token name: aliases repoint per theme and a name is not a value.
  • Ink on that ground — the reversed-out white against the caption ground it sits on. This one is ruled. The floor is 4.5:1, carried as constraints.$ink_rule.floor in the rails manifest, from s219-D3(2). A rung that breaks it is refused on the page, with the number.
  • Ground against ground — the caption ground against the page behind it, stated two ways: as a contrast ratio, and as ΔL*, the difference in CIE lightness. There is no ruled floor for this number. Nothing in canon, in the rails manifest or in the rulings record governs one ground against another. That absence is the reason this page exists, and it is the open question underneath the rung Dave picks.
  • Against light parity — the same separation expressed as a multiple of the light capsule’s. One means “exactly as separated as the light card you already accept”.

Two reference marks, neither of them a rule.

Light parity, 1.14:1 / ΔL* 5.20. Derived from the light capsule above. Landing the dark card here means the two modes separate their caption by the same amount.

The graphics grade, 3:1. Not a ground-against-ground rule — it is the grade this repo already applies to non-text marks (s132-D1, s168-D4, s168-D5, s176-D2). If ground-against-ground were ever given that grade, the caption ground would have to be at least #656565. That rung is drawn at the bottom of the ladder so the cost of writing such a floor can be seen rather than imagined.

Both are printed so the ladder can be read against something. Neither is proposed, and picking a floor is a ruling.

Sanity check on the arithmetic, not asserted: the rails manifest records the capsule/grey member at 16.48 in console dark. The same figure computed here from the rendered values is 16.48. The maths on this page and the maths in the manifest agree.

Rungs that already exist

The three grounds the console dark ramp actually holds

These are tokens. Picking one of them is a dial change: the value already exists in canon, has a name, and moves with the theme. Nothing has to be minted.

There is a catch, and it is worth saying before the pictures. Console does not carry its own surface ramp — it inherits the base dark ramp, and the surface part of that ramp is mode-inverted: the tokens that are dark greys in dark are light greys in light. So a token rung is usable here only as a dark-only repoint of the caption-ground slot. Repointed in both modes, the first two below take the light capsule to a pale ground with white ink on it and the light card breaks. Each rung carries its own light number underneath it, so this is checked per token rather than assumed from the family name.

The hole in the middle of the ramp, and what sits either side of it. The hover surface reaches ΔL* 4.45 — 0.77× the light card’s separation. It is the closest anything in the ramp gets, and it is just short. The next token the ramp holds is the disabled-action grey at ΔL* 21.33, 6.47× the light card. Between those two, console dark carries nothing at all, and light parity (ΔL* 5.20) falls in the gap.

So the token section offers a cheap answer that is slightly under the reference, and an expensive one well over it. Whether “slightly under” is enough is exactly the thing a number cannot settle — the cards above are there for that.

Rungs that do not exist

Derived steps — none of these is a token, and picking one is a promotion

Read this before the pictures. Every value below is a grey this page invented for the purpose of being looked at. None of them is in canon, none has a name, and none is proposed. Minting one is a promotion, and promotions are Dave’s. They are drawn here so a value can be chosen by eye, not so a value can be slipped in by a build.

And a minted token would be a pair, not a value: light keeps the ground it has today, dark takes the rung. That pair is the thing being promoted.

Not decided here

What this page deliberately leaves open

The rung. Which ground the console dark capsule caption takes. That is the question the page is for, and nothing above recommends an answer.

Whether a ground-against-ground floor gets minted from it. There is no such rule today, anywhere. Whichever rung is picked implies a number, and that number could become a floor that governs every caption ground against every page ground in all four themes — or it could stay a single value for a single chord member. Those are two very different rulings and the page does not choose between them.

Whether the same collision exists in mono, legacy and supercharge. Only console was measured, because the chord is console-scoped. Nothing here says the other three are clean.

Provenance: the chord and the ink rule are s219-D3(2) and s219-D3(3) chord one; the 4.5:1 ink floor is constraints.$ink_rule.floor in knowledge/_render/_bento_edit_rails.json; the console dark surface ramp is knowledge/canon/canon.css, the base [data-theme="dark"] block — console overrides radii and RAG hues there and does not override the surface ramp.

Where a chosen rung would get enacted. The rails manifest knowledge/_render/_bento_edit_rails.json is GENERATED — a hand edit is a red, because the selftest asserts the file equals a fresh generation. It is regenerated by knowledge/_render/gen_bento_matrix_217.py --rails and the library page is then rewritten by knowledge/_render/gen_foundations_217.py. A new token would additionally be a canon change, which is a promotion.
