Q-A · The crossing — three treatments, live (zoomed slice: Oct–Dec, line over bars)

A1 — control: naked line (no mechanism)

line vs bar fill 1.04:1 — both modes

The categorical set is isoluminant by design: no series pair separates a crossing. Shown as the attribute-the-diff control.

A2 — page casing (as built) REC

boundary = page vs bar: 5.26:1 L · 3.31:1 D

The markers' own series-fill + page-stroke halation idiom generalised to the line. The boundary contrast is exactly the bar's gate-checked figure, every theme, HC included. Line keeps its token identity (legend, filter, tips).

A3 — CSS invert (mix-blend-mode:difference, white stroke)

over page: 21.0:1 L over the bar: #766682 → #89997D, 1.73:1

Per-pixel inversion. Against extremes it is maximal (black on white); against the BRAND MID-TONES it lands on another mid-tone — 1.37–1.80:1 across the series set — and the line stops being a token (its colour becomes a function of whatever sits beneath, so dv-017/dv-016 have nothing to resolve, and light mode's line is near-black page-side while dark mode's is near-white: the identity flips per ground and per mode).

Measured difference-invert results over the set: series-1 #766682 → #89997D (1.73:1) · series-2 #A45C3A → #5BA3C5 (1.80:1) · series-3 #577C78 → #A88387 (1.37:1) · page white → #000000 (21.0:1). The invert is a contrast mechanism only against near-extremes; Apollo's categorical fills are deliberately mid-luminance, which is precisely where it fails. The casing also happens to be the only one of the three the existing gates can SEE (resolved tokens, not composited pixels).

Toggle the theme: the panel is dark in BOTH modes — your standing rule holds (dark-in-light is not inverted in dark mode; the surface token simply carries per-mode values, and here they coincide). The failure only exists in light mode because the PAGE ink is dark there.

B3 — tokenisation directions (research, not ruled)

O1 · Surface-classified ink — scoped re-resolution REC
A dark-in-light panel is a CLASSIFIED SURFACE (the ADR-0014 move: whites are classified, indices are semantic). Mark it data-surface="inverse"; text roles re-resolve inside it (text/default → the inverse ink) via the same cascade machinery as themes — no per-element colour choices, gates resolve it statically. The surface role CARRIES its ink slot the DV-D07 two-channel way: surface/x/{color, on}.

O2 · Paired on-* tokens — every surface token ships a sibling (surface/x + on-surface/x, the Material precedent). Same effect as O1 with a flatter shape; more token count, less cascade.

O3 · CSS invert / contrast-color() — rejected for text by the A3/B2 maths (mid-tones mud, 1.4–1.8:1); native contrast-color() is the future-CSS version of O1's intent, not yet usable. Track, don't build.

Gate consequence either way: type26-013 needs an INVERSE-SURFACE CARVE-OUT (white type legal where the enclosing surface is classified inverse — still red-only on page ground), and text directly ON series fills stays prohibited for body sizes (3.31–3.78 vs ink) — large/graphic ≥3:1 only, which is why the endkey sits ADJACENT, in page air, never on the bar.
