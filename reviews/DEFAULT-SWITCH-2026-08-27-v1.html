4 · Nothing was removed

All four treatments, still there to pick from

These are the four you called legal, drawn live in console. Each one was put through the repo’s own legality and reachability rules before it was drawn — this page refuses to build if any of them has stopped being an option. One of them is now the default; the other three are exactly as available as they were.

  • The rounding dial still carries both members in every theme: corners, capsule.
  • The caption-ground dial still reaches grey, white, darkgrey, transparent in console gallery — unchanged.
  • The two proposed exclusions are still proposed, both of them — the ruling expressly declined to promote them.
  • The size of the option space did not move: 864 legal gallery states in console, 648 in each of the other three. A default is not an option.

One honest footnote. The dark-ground treatment is legal and reachable, but the photography page cannot currently ship it as a default: that page’s compiled block is one declaration per theme and none per mode, and the dark ground is the one whose value differs by mode (that is the #220 lift). The generator refuses by name rather than quietly painting the wrong value. That is a property of that page, not a narrowing of the rails — the option is still yours to pick in the edit pass.
