Amber is the one hue whose two roles diverge — and you're right. Background #F0B13A (always black text, 9.16 ink) is the centre of your four candidates (F7B326 / EFB64F / F0AD19 / E8B048). But it's only ~1.9:1 on white, so it fails as a standalone glyph/mark (needs ≥3:1, WCAG 1.4.11) — hence the darker glyph #C58900 (3.02 on white · 6.25 on #111). Red / green / blue each use one value for both roles; only amber splits. "For amber we only have the belt."

C · The decision — wording only

Split the clause in {#dv-017}(a)

Before: "delta INDICATORS (text, arrows, spark end-values, RAG-style cells) may carry red/green…"

After: "delta INDICATORS (text, arrows, spark end-values) may carry red/green… Directional deltas are red/green ONLY — amber has no direction (R-D3 rule 2). RAG status is a separate concern, governed by R-D3; its manifestation is specified separately."

Recommendation: adopt the split. No values change — it just stops the rule from listing an amber-inclusive form (RAG) under a red/green-only heading.
