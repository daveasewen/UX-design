Slot contracts — 28 components, 42 drafts

reviews/SLOTS-DRAFT-2026-08-09-s140-v1.json · drafted 2026-08-09 (s140)

What this is. The s139 audit found 42 props that inject content rather than set a value. The schema you just amended (s140-D1) gives them somewhere legal to live: a slots map. I have drafted one slot entry for each. All 42 validate against the amended schema (28 of 28 components pass); a mutation test confirmed the validator refuses an entry with use stripped, so the green is real.

Nothing is ruled and nothing was written into the metas. These drafts live only in reviews/. Every capability string here — "data-series", "table-rows", "action-button" and the rest — is agent-proposed and unruled. If you want a different vocabulary, that is a decision, not a correction.

Four I am not confident about, flagged in red below: textarea.rows (a sizing number, almost certainly a false positive — I recommend rejecting it), segmented-control.content and cards.content (both read more like variant axes than slots), and empty-state.body (a plain string you may prefer to leave as a text param).

Your next action. Scroll, set accept / amend / reject per component, then press Build verdict at the bottom and paste the block into chat.
