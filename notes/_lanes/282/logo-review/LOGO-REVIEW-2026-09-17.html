The questions

Twelve radio groups over six questions. One choice each, a note if you want one, and a recommendation on every question except where an option is yours to write. The export records your pick beside the recommendation, so the record shows where you overruled me.

01

Exporter defect · BLOCKING

Evidencesha 2e929098155f187e4378c9ab72f7a53d757fc62cabab4cd34304dfe746850a4b

masterbrand-identifier-dark-colour.svg — the identifier is missing and the canvas is not.

The file is 2584 bytes, viewBox 0 0 795 85, 9 paths, ink stopping at x=314.2 — 39.5% of its own canvas. Its light twin carries a 5,020-character identifier path filled #333333 that reaches x=777. This file has no #333333 path at all. Byte-for-byte it is masterbrand-dark-colour with a wider viewBox: the diff between the two files is one viewBox line and one rounding digit. The probable cause is in our own exporter, measured. _export-logos.py's clean() strips <path d="M-?\d{3,}…" fill="white"/> — a rule written to remove Figma's white background path. In the light file the identifier path is <path d="M404.468…" fill="#333333"/>: it starts at x=404, so it matches the \d{3,} arm, and it survives only because it is not white. On a dark export the identifier is white. That is a mechanism, not a proof — confirming it needs a token and a re-export, which this lane does not do.

Clear space and minimum size

Evidenceva25-014 · visual-assets.md · ADVISORY

The numbers exist in the 2025 record and nowhere in the refresh. Which becomes the rule?

Measured: logos.md carries no number and says the standard lives on create.hsbc; knowledge/tokens carries no logo clear-space or minimum-size token; and a grep for clear, minimum and NNmm over the whole brand-refresh source snapshot (11,836 bytes) returns zero matches. The refresh page does not carry a number. The corpus does, once, in the 2025 page: va25-014 — “clear space = 1× hexagon height on all sides; minimum size = 7mm hexagon height / 105×20px / 26×7mm; positioning = top-left or bottom-left, inset 1× hexagon from edges”, filed ADVISORY.

Hexagon alone

Evidence4 hexagon nodes · 0 references · 1 deliberately-unbound component

Which components, if any, may show the hexagon without the wordmark?

va25-016 fences it: hexagon-only use needs Create Direct approval AND ‘HSBC’ context nearby — the examples given are app tile, profile avatar, favicon. logo26-007 adds partnerships where HSBC is well known. All four hexagon files are referenced by nothing today.

Guideline shape

Evidencelogos.md: 0 rules · brand-refresh-assets.md: 7 logo26-* · visual-assets.md: 4 va25-01[4-7]

Do logos.md and the brand-refresh-assets.md logo section merge, or does logos.md become a pointer?

logos.md is 27 lines: a sticker-sheet description of the 12 variants, the export receipt, and a pointer to create.hsbc. It carries 0 rules in the rules index. The refresh file carries logo26-001..007. The numeric rules — clear space, minimum size, positioning — sit in a third file, visual-assets.md (va25-014..017). So the logo standard is currently spread across three files and the one named ‘logos’ is the only one with no rules in it. bra26-003 asks that the legacy files stay as the 2025 record.
