## 1 · `aca-003` — `accessibility-content-authoring.md` · BLOCKING

**Rule:** CA-3 — unique, concise page/frame/iframe titles (SC 2.4.2 A + 4.1.2 A): first thing a
speech-output user hears.

**His note:** "This is interesting, so a designer may argue that an active navigation element might
be enough for orientation at the top level of at least, sometimes a salutation might be the first
heading and sometimes it might be more marketing lead messging."

**If inscribed:** the rule would gain a stated exception for top-level pages where an active
navigation state already carries the orientation, which weakens a WCAG-A obligation and is therefore
the one row here that cannot be settled by taste alone.

## 2 · `aid-009` — `accessibility-interaction-design.md` · BLOCKING

**Rule:** ID-26 [introduced 2024] — target size, the formal 2.2 rule: HSBC DEFAULT 44×44, minimum
exception 24×24 (SC 2.5.8 + 2.5.5): 24 only with the spacing/equivalent/inline/UA/essential outs;
"HSBC already has formal design guidance… 44×44 is therefore considered the default requirement."

**His note:** "So this is about the actual size of the visible target, we have a 44px invisible hit
area to meet the rule, this doesn't take into account context, the clear area around the target
spacing can create emphasis also, we also have compact views to think about, but that would be a
user choice. I like this principle, but it feels too boolian, maybe we need to discuss."

**If inscribed:** the rule would have to say whether 44 is measured on the VISIBLE target or on the
hit area, and admit clear space and compact views as context — which is a substantive rewrite, not a
clarification. **This is an ASK: he said "maybe we need to discuss".**

## 5 · `dv-bar-007` — `data-visualisation-bar-charts.md` · BLOCKING
