### 3 · The two-index question, closed

`s215-D5` (1) says two indexes must not coexist to drift. Enacted as **one owner, one file**:

* `gen_library_214.py` writes `showroom/index.html` and stamps
  `<!-- APOLLO-LIBRARY-INDEX v2 (gen_library_214.py) -->` into it.
* `gen_showroom.py` writes **no** index, protects that file from its prune, and its `--check`
  bites when the file is missing **or** carries no sentinel (i.e. when a v1 index has come back).
* The `#214` address `reviews/LIBRARY-2026-08-21-v2.html` is **kept alive as a generated
  redirect**, not deleted: `knowledge/_state.json` row `W-99zg` homes there, and deleting the
  file would rot a live address (WRITE-ONCE addressing, ADR-0017). The stub carries no copy of
  the library, so there is nothing there to drift.

The old sync gate said *"N page(s) + index in sync"*. It still says it, it still passes, and it
still bites — on someone else's artefact now, which is why the sentinel exists.

### 5 · Thumbnail machinery

`knowledge/_render/gen_thumbs.py`. 135 PNGs at **320×200** (640×400 CSS px at
`device_scale_factor=0.5` — no resampling step, no Pillow dependency), light mode, one width,
into `showroom/_thumbs/`. **Total 1.4 MB**, mean ~10 KB per file; nothing was compressed into
unreadability and the shots were read at full size to confirm the type renders in the licensed
HSBC cut.

Runbook rules obeyed (`knowledge/_RUNBOOK-render-verify.md`, read first):

* **`goto file://` only** — `set_content` is banned and is not in the file; a srcdoc/no-URL
  document drops `type.css` silently.
* **Canvas font probe with two controls, not `document.fonts.check()`** — measured
  `HSBC_MtUnivers_Latin` **347**, both aliases **347**, `DejaVu Sans` **375**, nonexistent face
  **301**. The probe *discriminates*, and the script **refuses the run** if it does not.
* **Chunked** across bash calls (`--range 0:12`, `12:80`, `80:135`, `--resume`), because sandbox
  calls die at ~45 s wall. 0 failures across all three chunks.
* `/var/tmp` for browsers, libs, fonts and scratch; symlink font farm; **0 `.uuid` strays** in
  the repo (`git status` shows no font-cache files).

The library only *addresses* the thumbnails. A missing PNG degrades to a `no thumbnail`
placeholder on the card and is reported as a residual — never faked.

### 10 · CONSEQUENCES AND PITFALLS (mandatory, Dave #165)

1. **⛔ `gen_showroom.py` will delete the library if `PROTECTED` is ever dropped.** Its orphan
   prune removes every `showroom/*.html` not in its own `files` dict, and the index is no longer
   in that dict. One line stands between a routine regenerate and a deleted index. The
   `--selftest` bite 6e exists for exactly this and must not be "tidied".
2. **⚠ The `--check` index leg cannot see CONTENT drift, only presence + sentinel.** If
   `gen_library_214.py` is not re-run after a snippet is added, `gen_showroom --check` passes
   while the index is stale. The real guard is `gen_library_214.py --check`, and **neither
   generator is wired into `_build_all.py`** (unchanged from #214, and out of this lane's fence).
   Until they are, the two `--check`s must be run by hand, in that order.
3. **⚠ Two derivations are now load-bearing and neither is ruled.** Usage group (§4) and status
   (§6) both appear on the face of the page as if they were facts. They are proposals with an
   override point each. A reader — human or agent reading `index.json` — cannot tell a derived
   status from a ruled one. If that matters, the fix is a `"$derived": true` flag per field, not
   a footnote.
4. **⚠ A thumbnail is a photograph, and photographs go stale silently.** `showroom/_thumbs/*.png`
   is not regenerated by anything that runs today. Change a component and its card keeps the old
   picture with no gate to say so. The cheap remedy is a staleness check (thumbnail mtime vs its
   showroom page's) in `gen_library_214.py --check`; it is **priced, not built** —
   [[instrument-without-a-consumer]] cuts the other way here, so it is named rather than added.
5. **⚠ 1.4 MB of binaries enters the repo.** 135 PNGs. That is the first bulk-binary addition to
   `showroom/`; if the library grows to 300 components it is ~3 MB, and re-shooting them all on
   every visual change re-writes every blob. Not a blocker today, named for the day it is.
6. **★ A card that measured 2px taught something about grid + `overflow:hidden`.** Every gallery
   card collapsed to its 2px of border while its children laid out at 302px
   (`offsetHeight 2`, `scrollHeight 302`, `gridTemplateRows "230px 2px 2px…"`). The first
   diagnosis — "`<button>` sizes its anonymous inner box wrong" — was **wrong**, and swapping to
   a `div` did not fix it; `overflow:hidden` on the grid item did. The comment in the CSS records
   the measurement, and the JS comment records that the element swap was **not** the cause, so
   the false reading cannot be inherited as a fact [[premise-ages-faster-than-rule]]. The `div`
   swap was kept on its own merits (a `<button>` may not contain flow content).
7. **⚠ The drive harness has two potholes worth 30 s each**, banked in
   `drive_library_215.py`'s docstring: `page.click("body")` now lands inside the card gallery and
   *opens a component* (it is not a neutral click any more), and playwright's auto-scroll does
   not reach into the gallery's ~6000 px nested scroller — narrow with the search box first.
8. **⛔ Nothing on the DO-NOT-RULE fence was touched.** `knowledge/_rulings.json` was read only.
   No ruling, constant or threshold was made or moved; no Dave-owned item was closed; nothing was
   promoted into derivations; no component visual identity was altered — every specimen is still
   an iframe of the gated showroom page and every thumbnail is a screenshot of one. No commit, no
   push, no `_build_all.py`, no `GOOD-MORNING.md` / `_LIVE-STATE.md` / `_CHAIN.md` / MEMORY.
