## Mandate

Build `W-45` exactly as scoped in the programme brief Item 2:

1. **Probe registry** — a directory `knowledge/_probe_registry/` + a manifest
   (`manifest.jsonl` or similar; your schema choice, PROPOSED not ruled). One scripted probe
   per historically-found defect class, starting with the five named in the scope: meta-schema
   sweep · duplicate-ID/IDREF scan · dangling-var pixel test · premise-vs-store diff ·
   stale-figure grep. Mine `_DECISION-HISTORY/`, `notes/_MEMENTO-DECISIONS.md` and
   `knowledge/_DS-IMPROVEMENTS.md` for the receipts that define each class — each probe's
   manifest row cites the session(s) where the class was actually caught.
2. **`caught:` ledger** — the manifest carries a per-probe ledger; the promotion evidence IS
   the ledger. Seed it with the historical receipts you mined (named, probeable pointers).
3. **Promotion rule as code** — a small tool that reads the ledger and emits the twice-caught
   candidates (two DISTINCT sessions, receipts named). It writes candidature text for
   `knowledge/_DS-IMPROVEMENTS.md` but DOES NOT write that file — output to stdout/receipt;
   promotion is Dave's (derivation governance).
4. **Selftests** — every probe gets plant-then-detect BOTH directions (plant a defect → probe
   fires; clean tree → probe silent). [[mutation-tests-the-clause-not-the-feature]]: the
   selftest must DRIVE the probe on a real planted artefact, not assert on the probe's clause.
5. **Drive the registry once on the REAL tree** and record what it finds (or that it finds
   nothing) — a probe never run is an instrument without a consumer.

## Consumer at birth
