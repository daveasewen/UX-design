## 2. Two decisions worth naming

**(a) The demo var is renamed, not fenced — and it is DEFINED, not just defaulted.**
The probe's example was `.dg{width:var(--dg-max,760px)}`. I went one step further and wrote
`.wrap{--tr-w:720px; width:var(--tr-w)}` — the var is *declared in the same rule*. Reason: these
rules are projected into `canon/canon.css` by `gen_canon_components.py`, and `_validate_compose.py`
fails on any `var(--x)` in canon.css with no matching `--x:` definition **regardless of a
fallback** — `--demo-width` only survives today because it is hard-listed in that gate's
`RUNTIME_VARS` (`_validate_compose.py:42`). A bare rename to a fallback-only var would therefore
have reddened the compose gate on the next canon regeneration. Declaring the var keeps the harness
override working and needs no new exception list.
⚠ `_render_links.py:32` and `_render_tags.py:13` were read before renaming: **neither touches a
snippet.** Both point at `knowledge/_fitness-test/tags-responsive.html` / the links fitness file and
set `--demo-width` on `#filterbar` / `#related` *there*. Lane C changed no fitness-test file, so
those two scripts still work. `RUNTIME_VARS` is left untouched (lanes A/B still need it).

**(b) Five templates carried ONE script holding chrome AND component behaviour — I split it, I did
not fence it.** `Template-dashboard`, `-detail`, `-list-index`, `-report`, `-settings` each ship a
single `<script>` whose comment says "DEMO CHROME ONLY" but which also contains `moveInd()` /
`moveTabInd()` — the segmented/tab **indicator position, which must be measured after layout**.
Fencing the block wholesale would have deleted real component behaviour, so each became two
scripts: an unfenced component script (the measure function, its click wiring, an initial call and
its own `resize` listener) and a fenced chrome script (theme toggle + the `wOut` width read-out).
**Proved, not asserted:** the indicator's measured width is unchanged with the fence intact AND
after the fence is deleted — report 107/107 · dashboard 81,89/81,89 · detail 89/89 · settings
52,52/52,52 · list-index 89/89.
