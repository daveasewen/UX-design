### Per entry (as § 5, with the choices named)
`component` const; `description` = purpose + " When: " + gate; every meta setting as an A2UI property — a `bindsData` setting is A2UI data (`DynamicString`/`Number`/`Boolean`, or `oneOf[array|object|DataBinding]` for a series or table) carrying `x-apollo: {data, capability, shape}`; an `ownText` setting carries `x-apollo: {ownText, items}`; an enum setting that also binds data (chart-bar's `series` mode) stays an enum with the binding on `x-apollo`; `variants` as a `variant` enum; every slot as `ComponentId` or `ChildList` with `x-apollo: {slot, accepts, multiple}` (the wall's `tiles` is the set's one `ChildList`). One `x-apollo` block per entry: slug, meta path and sha, level, status, proposal, provides, answers, shape, span, priority, `when {gate, prose, fields}` (the when-field names the gate uses, from `when-fields.json`; `needs` shows up here for data-grid), variants, settings/dataSettings/ownWords, slots, `states` (from `stateModel`: the list and one sentence per state), a11y {role, sc}, snippet, rulings (governs/obeysAuthored/obeysDerived/routed count, the reader's), aliases, and `spec` when the meta carries `anatomy`/`states`/`emits`/`bindings`/`$extracted` (`s311-D4`, lane L's today: read if present, never required; 0 of 17 carry them at this sha).
Required: a required slot; a data setting whose shape is not `no-data × …` AND that has no default; an own-words setting with no default. Not published: alias metas, deprecated parts, any meta the schema rejects (0 at this sha).
The catalogue also declares `functions: {}` and `$defs.anyFunction = {not: {}}`: A2UI's `DynamicString`/`Boolean` reach `catalog.json#/$defs/anyFunction` through `FunctionCall`, and without the def the validator raised on the first required boolean (hit on the all-parts catalogue, not the dashboard). The PoC defines no functions (`s305-D46`), so a function call in a setting value is refused.

### Versioning (§ 5, the API)
`catalogId` = `https://apollo.invalid/catalogs/apollo-launchpad/dashboard/v0.1.0/catalog.json`. `x-apollo.catalogue` = `{name, version, sha256 (canonical components + $defs), metas_sha (git HEAD at build, or --metas-sha), metas_sha256 (the metas' bytes), parts, previous}`. The patch bumps when `sha256` changes against the file already in `out/`; otherwise version and `previous` carry forward, so a re-run is byte-identical (T1.6, T1.6b).
