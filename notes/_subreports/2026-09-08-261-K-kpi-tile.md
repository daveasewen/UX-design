## What changed, in design terms

1. **Bento spans are real.** The board is a 12-column grid; every tile declares a span the meta already
   legalises (compact/default 3, with-target 4, hero 6) and re-spans at 900px and 560px rather than
   reflowing — s248-D3, because an edit mode is coming.
2. **Rows reserve their slot.** Every row sets `min-height:var(--slot)` — the height its own type
   composite already publishes in `type.css` and which is inert until something reads it. Neighbouring
   tiles now align label, value and delta rows even when one tile carries no delta. Nothing was appended
   to `type.css`; binding stays the T-D14 markup-class pattern, so blast radius is unchanged and
   TYPE-002 contribution is still 0.
3. **The delta glyph is the HSBC trend mark.** Geometry byte-matched from
   `status-icons/trend-positive|trend-negative|indeterminate`, recoloured to currentColor. ⚠ This is a
   **DEPARTURE from Stat card** (which uses `arrows-and-chevrons/arrow-up|down`) and it is drawn, not
   ruled — both glyphs sit side by side on the review page.
4. **Two new slots.** A **target/progress row** with NO hue at all (track = border/subtle, fill =
   standing ink, one-pixel pace tick, caption spelling out every figure the bar draws) and a **spark
   slot** re-scaled to 28/40/56 with a low-alpha area under the line.
5. **Four states, drawn not described.** loading (skeleton, `aria-busy`, pulse killed by
   `prefers-reduced-motion`) · empty (em-dash + a sentence saying why — never a zero) · error
   (`role="status"` + a 44px control that names what it loads, never "Retry") · stale (a **neutral**
   marker chip, deliberately not amber — Dave is astigmatic and yellow is a problem hue).
   A whole-tile **link** variant is drawn as a rival to s182-D2's opt-in icon button; both are in the file.

Variants now: default · compact · hero · with-sparkline · with-target · as-link · with-table-cta.
`stateModel` moves from the bare string `"simple"` to a five-state object.
