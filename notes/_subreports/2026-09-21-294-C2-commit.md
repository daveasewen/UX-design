### `✗ could not stage 'notes/_BUILD-VERDICT-LOG.jsonl'` — THREE TIMES, VERBATIM


⛔ **THE CAUSE WAS MY OWN PRE-STAGING, AND IT IS A REAL MECHANISM, NOT A FLAKE.** I had staged all
24 paths by hand earlier in this lane in order to prove the `s294-D2` arm's bite against a real
staged index. That made every `git add` in the script's per-path loop a **no-op**, and on this
mount a no-op `add` is fatal to the next one. Measured directly, three consecutive adds:

```
$ git add -- knowledge/_gen_size_stamp.py          # already staged, nothing to write
warning: unable to unlink '…/.git/index.lock': Operation not permitted
rcA=0                                              # SUCCEEDS — and LEAVES a 0-byte index.lock
$ git add -- notes/_BUILD-VERDICT-LOG.jsonl
fatal: Unable to create '…/.git/index.lock': File exists.
rcB=128
$ git add -- knowledge/_build_survey.py
fatal: Unable to create '…/.git/index.lock': File exists.
rcC=128
```

**Why:** when `add` has nothing to write, git **closes and unlinks** its lockfile instead of
renaming it over the index — and the sandbox delete-guard refuses that unlink, so the lock
survives. When `add` has real work, git **renames** the lock over the index, the lock name
disappears, and consecutive adds are fine — asserted the other way on the same three paths after a
`git reset`:

```
knowledge/_gen_size_stamp.py rc=0 · notes/_BUILD-VERDICT-LOG.jsonl rc=0 · knowledge/_build_survey.py rc=0
.git/index.lock: No such file or directory     # three adds, no leftover
```

**Fix: `git reset -q` to empty the index, so the script's own loop had real work at every path.**
⛔ **The script was not edited, no gate was touched, and `DOC_ROW_ACK` / `POLARITY_ACK` /
`SESSION_ACK` were never used.** ⚠ **The declared cost of that fix:** with an empty index at the
seam, the `s294-D2` arm emitted its UNKNOWN-never-green note during the script's own wrap gate
rather than its bite — **which is exactly the declared gap this lane wrote into the arm**, arriving
on the first run after it was written. The bite itself is proven above against the pre-staged
