`(None, None)` no-opinion exit **before** the receipt-existence and source-hash arms. The driver
only measures `dv004_px` on radial and stacked joins, so for 12 of the 13 engine pages every
figure carries `dv004_px: null` — the function returned no-opinion and the STALE arm was
unreachable. Editing an engine source and never re-driving left the gate GREEN; only
`_drive_chart_engine.py --check` caught it.

**The change.** For ANY member named in `ENGINE_TEST_PAGE`, the order is now: unmapped ⇒
no-opinion (the rule is still not widened) → no receipt file ⇒ BLOCKING → no receipt entry for the
page ⇒ BLOCKING → any recorded source hash that no longer matches the bytes on disk ⇒ BLOCKING,
naming the stale file and `python3 knowledge/_drive_chart_engine.py` → and only THEN, if no
`dv004_px` figure was measured, `(None, None)`.
