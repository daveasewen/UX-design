### Blocking a designer's first hour

**F5 — `tiktoken` is called optional, but the wrap step hard-refuses without it.** ⛔ **BLOCKING**
FIRST-SESSION.md:256 — *"**Optional:** `pip install tiktoken` makes the chain's size figures accurate.
Without it the generator falls back to an estimate and says so in its own output — which is the honest
behaviour, not a fault."* Driven with `tiktoken` blocked, both arms fail:
> `✗ _CHAIN.md NOT generated — the token measurer is running on the ESTIMATE fallback … chain NOT generated/verified. This is a MEASUREMENT REFUSAL … Re-run once tiktoken is installed and can reach openaipublic.blob.core.windows.net` — **exit 1**, and `--check` likewise exit 1.

There is no estimate fallback; the generator declines to write. The consequence is the whole point of
the walkthrough: Step 4c is what replaces the starter `_CHAIN.md`, and the starter chain is what puts
Copilot in **Arm 0**. A designer on a clean machine finishes the guided session, gets a red, and next
morning Copilot greets them as if the pack had never been used — the entire first session evaporates.
It also contradicts FIRST-SESSION.md:32 — *"You need Python 3 and VS Code with GitHub Copilot. **Nothing
else — no install, no account, no API key.**"* — since the wrap needs a `pip install` **and** an
outbound call to `openaipublic.blob.core.windows.net`, plausibly blocked on a corporate design laptop.
*Class:* documented-optional dependency that is actually required (today's "green over an artefact that
cannot RUN", inverted — a doc green over a step that cannot run on the machine it describes).
*Fix, priced:* Dave's call between (a) make it truly optional — let the estimate path write and stamp
the file `ESTIMATE`, ~40 lines in `_gen_chain.py` + 1 line in FIRST-SESSION; or (b) tell the truth —
move `pip install tiktoken` into §Before you start as required, ~3 lines, and note the network host.
(b) is ~300 tokens; (a) is ~2K tokens and changes an artefact's honesty contract.

**F3 — the first retrieval attempt misdirects to a script the pack does not carry.** ⛔ **BLOCKING**
`.github/copilot-instructions.md` operating rule 2 tells Copilot to retrieve via
`memento-package/machinery/_memento_search.py`. On a fresh pack:
> `memento-search (Memento door): index missing at …/_memento-index.json — run the build (python3 knowledge/_build_all.py); REFUSING to search nothing.`

`knowledge/_build_all.py` is **not in the pack** (probed: `find . -name '_build_all.py'` → nothing;
not in the manifest ship list). The script that *does* work ships two directories away as
`memento-package/machinery/_build_memento_index.py`, and I drove it clean. So retrieval is one
correct filename away from working and the error sends the designer to a dead end.
*Class:* repo-only tool named in a designer-facing refusal (the class this lane was asked to file).
*Evidence of home:* `memento-package/machinery/_search_core.py:152`.
*Fix, priced:* repoint one f-string at `_search_core.py:152` to `python3 machinery/_build_memento_index.py`
— **~150 tokens, 1 line, 1 file.** Cheapest high-value fix in the lane. ⚠ Note this is *narrower* than
the three priced options in the #220 addendum: the builder already ships and works; only the signpost is wrong.

**F11 — the gate runner discards the population, so "a green that graded nothing" is invisible.** ⛔
`ci-template/README.md:34-38` — *"Three of them grade **your** work … They will pass loudly with a
population of zero until your work is where they look. A green that graded nothing is not the same as a
green that graded something, **and the runner prints the difference.**"*
It does not. On a virgin pack all 35 gates print an identical bare `pass`, including the three named.
Probed: `grep -in "population\|graded nothing\|zero" gates.log` → **no matches**;
`grep -n "population\|graded\|zero" ci-template/run-gates.py` → **no matches** — the runner has no such
logic at all. The gates themselves *do* emit it and the runner throws it away:
> direct: `✅ CSS-governed gate passed (**0 tranche file(s)**).` · `_validate_radius: 0 strict fail(s), **0 advisory file(s)**`

So a designer's first mechanical proof reads `35 pass` while three of those graded nothing.
*Class:* documented consumer for a signal nobody emits — [[instrument-without-a-consumer]] inverted.
*Fix, priced:* have `run-gates.py` echo each gate's own last line (or parse a trailing `(N file(s))`)
next to `pass` — **~600 tokens, ~15 lines, 1 file.** Blocking-ness is Dave's: it is a reporting fix, not a verdict change.

**F12 — on a designer machine without playwright, 2 of the 3 browser gates are counted as build failures.** ⛔
`ci-template/README.md:46-51` — *"**COULD-NOT-ASK** … Exit 77. **This does not fail the build.** … A check
that cannot run is not a check that passed, and it is not a check that failed either — pretending
otherwise is how a suite goes quietly blind."* Driven with `playwright` unimportable:
> `python3 ci-template/run-gates.py --browser` → **`0 pass · 2 FAIL · 1 could-not-ask`**, exit 1

- `_validate_state_contrast.py` → **raw unhandled traceback**, `ImportError` at line 53, counted FAIL

The `render` CI job will therefore be red for every adopter who has not run `playwright install`, in
exactly the way this README promises it will not be.
*Class:* refusal that cannot express itself in the runner's vocabulary — [[honest-refusal-needs-a-legal-form]].
*Fix, priced:* wrap the import at `_validate_state_contrast.py:53` in the same guard the other two use
and emit the marker + `sys.exit(77)`; add the marker + 77 to `_validate_descender_computed.py`
— **~700 tokens, ~12 lines across 2 files.**
