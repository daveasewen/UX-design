# #261 lane L — the legend becomes a placeable component

**What was true before.** `knowledge/canon/dv-legend.js` has existed since #70 as the registered
legend interaction model (DV-D11 · DV-D13 · DV-D17 · DV-D18 · DV-D19), consumed by ten chart
members. There was **no `legend.meta.json` and no `Legend.reference.html`**, so the legend was
reachable only by being *inside* a chart figure: a dashboard could not place one shared key for a
row of small multiples. That is the gap this lane closes.

**It consumes the engine; it does not fork it.** Not one line of legend behaviour is authored in
the snippet. `Legend` is registered as a `dataviz` `$members` row with `"consumes": ["dv-legend"]`,
and `gen_component_partials.py` injects `canon/dv-legend.js` between the AUTO-BEHAVIOUR markers —
the same bytes every chart gets. Page cost: **7,734 code-only bytes of PAGE_BYTES 34,816** (s250-D1
caps unmoved; the cheapest member of the group after nothing).

## What the component provides

Swatch (colour, optionally plus an **angular shape or line style** — square / triangle / diamond /
bar / solid / dashed / dotted, the WCAG 1.4.1 second channel; the clip lands on the mark `::after`,
never on the target `::before`) · key letter · label · optional **value / percent / delta** ·
**swatch toggle** (`role="checkbox"` + `aria-checked`, show-hide) · **label toggle** (`aria-pressed`,
isolate) · Reset · one sr-only `role="status"` live region per legend.
**Orientation** horizontal | vertical. **Placement** top | right | bottom (left deliberately absent
— a key before the thing it keys). **Overflow** wrap | scroll, one required (a legend that does
neither widens its host, which is how a bento tile breaks — s248-D3). Responsive: the right-placed
column folds under the canvas below 640px, in CSS, with no resize listener.

**Two-red law (s151-D1).** The delta numerals are the only coloured text on the page: `#DA1A00` /
`#137F3C` light, `#F6604C` / `#66CC8D` dark, bound to `rag/error-ink` / `rag/success-ink`.

**Hit targets.** 44px everywhere, via the invisible `::before`. The lane brief asked for 24; the
repo already holds Dave's 2026-07-25 ruling, quoted in the donut legend block — the swatch is ONE
component, "44 EVERYWHERE … reverses the 24px dense-case proposal". A lane does not re-open that,
so 24 is recorded in the meta as the floor a dense variant *would* sit on. See item 1 below.

**Shared legend.** What ships is **scope**: dv-legend resolves its marks with
`host.closest('figure')`, so one legend and three canvases in one `<figure>` is a shared legend by
construction — driven and measured below. `data-dv-controls="<chart id> …"` ships as a **contract
only**; the engine does not read it. Widening dv-legend's resolution from `closest('figure')` to a
document-wide id lookup changes what all ten chart legends control — an engine change with a blast
radius, not a component's own business. See item 2.
