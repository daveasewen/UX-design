## 2 · What it measures, in one paragraph

For each component family the built file **attempts**, it scores **FIDELITY** = the fraction of that
region's structural fingerprints that also exist in the family's snippet. Fingerprints are
**structure only**: an element token is `tag` + its *canon* classes sorted, and two shingle kinds are
emitted — `ANC` (`A>B>C`, an element plus its two nearest canon-class-bearing ancestors) and `SEQ`
(`P:[a<b]`, ordered pairs over a canon parent's distinct canon children). Text, aria text, data
values, ids, `d` paths, attribute order, class order, whitespace and page-local class names are all
outside the token by construction. Elements with no canon class are **transparent** — skipped in
ancestor chains and lifted through in child lists — so page furniture wrapped round or pushed inside
a component cannot move the reading.

**Everything is derived at run time** from `knowledge/snippets/*.reference.html`: the family list,
the canon class vocabulary, each family's distinctive ("own") classes by document frequency
(`df <= 3`), and every shingle vocabulary. There is no baked list. This was **proved live, by
accident**: the sibling bento lane minted `Template-dashboard-bento.reference.html` mid-session and
the corpus went 135 → 136 families with zero code change, and the new family appeared in the
dashboard readings unprompted.

Grades: `SPLICED` / `PARAPHRASE` / `ABSENT` / `NO-VERDICT` (thin evidence — named, never defaulted to
a pass) / `SHADOWED` (see §4). Exit codes: `0` all spliced · `1` any red · `2` named refusal ·
`3` no verdict. Every refusal carries the marker `REFUSED (detect-retrieval)` on stderr.

**FIDELITY IS PRECISION, NOT RECALL, AND THAT IS A DESIGN DECISION WITH A TEST BEHIND IT.** Trimming
a canon component (keep the chart, drop the sort switch) is legitimate and must never red; inventing
structure is the tell. COVERAGE (recall) is reported beside fidelity as information and is never the
grade. Selftest arm P proves it: a trim holds fidelity at **1.000** on all five real subjects while
coverage falls to 0.42 / 0.42 / 0.31 / 0.29 / 0.57.

## 4 · TWO FALSE-RED CLASSES FOUND BY DRIVING IT, BOTH FIXED, BOTH SWITCHABLE

The brief's named pitfall — *"false reds on legitimate variation kill trust in the instrument on day
one"* — arrived twice, and neither was visible from fixtures.

**F1 · FALSE ATTRIBUTION.** The dashboard has **one** line chart. `Chart-combo` and `Template-report`
went red on it, because those families share `dv-target-label` / `dv-toggle-seg` / `dv-ghost` with
`Chart-line`; `Template-report`'s reading then swept in the page's KPI cards as well. Two remedies,
both reported, both defeatable with a flag so the raw reading stays inspectable:

- **REGION** (`--no-region` to disable) — a family is graded only over the part of the page its own
  distinctive classes sit in. The region grows upward from each anchor and **stops before it would
  swallow another family's anchor**.
- **SHADOW** (`--no-shadow`) — overlapping regions have ONE provenance: the best-fitting family
  carries the verdict, the rest are reported `SHADOWED-BY <family>` with both fidelities printed.
  Named, never silently dropped, and never counted as a red.

Measured, mutation-tested both ways (arm N2): reds on the regen go **5 → 2**, suppressing
`Chart-combo`, `Filter-toolbar-bar`, `Template-report`; with the flags off they come back.

**F2 · A LEGITIMATE TRIM WAS READING AS DRIFT.** The first build emitted SEQ shingles as sliding
3-gram windows over a parent's canon children. Deleting one canon child turns `P:[a,b,c]` into
`P:[a,c,d]` — a sequence canon never contained — so **trimming a component scored 0.72–0.84 on five
real snippets**. Arm P caught it and went red on the true code. SEQ is now **ordered pairs of
distinct canon children** (`P:[a<b]`), which are subsequence-stable: a trim only ever removes pairs
(precision holds at 1.000), a reorder manufactures reversed pairs, an inserted canon child
manufactures new ones. Children are de-duplicated by token first, so a chart with 5 bars and one with
12 read identically.

⚠ **F3 · A KNOWN BLIND SPOT, NAMED ON THE READINGS PAGE AS SAMPLE P5, NOT HIDDEN.** Stripping canon
class names *entirely* makes elements **invisible** to the reading rather than wrong, so fidelity can
**rise** as the denominator shrinks (P5: fidelity **0.796**, above the drift-1 sample's 0.791, while
coverage stays high at 0.908). `--min-shingles` only partially covers this. Whether the dial needs a
**coverage floor** beside the fidelity floor is on the readings page as a ruling-shaped question,
with both costs stated — it would close the blind spot and would also red a legitimate deep trim.
