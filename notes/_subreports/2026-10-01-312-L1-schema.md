- `states`: `{states[] (unique, ≥1), initial, transitions?[{from,on,to,guard?}], keys?{}}` — Zag-shaped per the sketch; `transitions` and `keys` optional inside so a passive part (table, `interactive:false`) can carry a one-state machine honestly. Distinct from `stateModel`, which is not touched.
- `emits`: `[{name, detail{}, when?}]`, `name` lower-kebab, `detail` key → type word, `[]` a positive declaration. `behaviour.events` untouched (s245-D4).
- `bindings`: `{"--var": "{group.token}"}` — keys `^--[A-Za-z0-9_-]+$`, values `^\{[^{}\s]+\}$`. Today's slash path is refused at the schema; resolution against `knowledge/tokens/` (dot → slash until `s311-D8` lands) is L2's coverage rule, because the schema cannot see the token store.
- `$extracted`: `{by, date, reviewed, source?, sha?, fields?[]}`. REQUIRED on any meta carrying one of the four (`dependencies`), so a draft can never pass as authored; Dave's ruling flips `reviewed`.
- Alias fence: the four + the marker join the s210-D5 `not.anyOf` list; `maxProperties 14` unchanged.
