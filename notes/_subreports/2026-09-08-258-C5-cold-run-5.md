## Creativity judgement (labelled as a judgement)

The rewrite bought a **derivation layer plus a router** — one `DATA`, one `rows()` predicate every
panel reads, one `renderAll()`, and the freshly emitted SVG handed back to a *carried* behaviour by
dispatching `resize` so `dv-behaviour.js` re-fits geometry that did not exist when it loaded. None
of that can belong to a component: no snippet knows which filter drives it, no template knows it has
four views, and no file in the library can hold the sentence *"when the entity changes, the corridor
chart's domain changes too."* A 2a-bound build copies every component and connects none of them.
What the rewrite also invites is authored bugs — F02 is one.
