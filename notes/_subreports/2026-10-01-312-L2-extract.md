## What the extractor reads and what it writes (the method, so nobody re-derives it)

Anatomy: the snippet body is parsed to a tree; the ROOT is the first element whose tag, implicit role or class has a name affinity with the meta name (exact token → initials → prefix/suffix/substring ≥ 3 → consonant skeleton), else the first non-harness candidate; then the richest instance of that signature (a gallery shows the part in several states, the fullest carries every part), then a climb while the parent is styled, has a role or ≥ 2 rules, no caption/heading child and is not a gallery. Repeated siblings collapse to the first with `$repeat`; their state attributes and `.is-*` classes are lent to the kept node as holes (`"aria-current": "{state.current}"` on the page link came from the sixth link). Demo chrome (captions, id-less headings, `.row/.gallery/.board/.nwrap` wrappers) is pruned. Variant classes named by a meta enum prop become prop holes (`"class": "btn {props.type}"`, `"split-btn {props.tier}"`, `"metric-delta {props.trend}"`). Every node carries `$sel`, the tag.class path from body, which is what the coverage check resolves.

States: the corpus's own words — `:hover` → hover, `.is-pressed` → pressed (`:active` folds into it when both exist), `[aria-expanded]` → expanded, `.open` → open, `.is-error` → error; `stateModel.states` (metric) and the prop named exactly `state` (button, accordion, dropdown) come first and set the initial; `$sources` names the selector, attribute or script handler each state was read from; `$initial` says why the rest state is named as it is. Transitions: the pointer/focus/disabled arrows the CSS implies plus `* → <state> on <event>` for every listener whose handler adds a class or sets a state attribute. `keys`: key names read from the script; the ACTION words are the APG defaults (declared in `$keys-source`).

Emits: read from `dispatchEvent(new CustomEvent(…))`. NO cohort snippet dispatches one, so all fifteen carry `emits: []` (the schema's positive "fires nothing") and `$extracted.$listeners` carries the DOM events the script attaches, so the page can say "listens: click, keydown · fires: nothing — Dave's call".

Bindings: `#token-manifest` `vars` → `{a.b.c}`; each resolved through `gen_snippet_tokens.resolve` (light, then dark/modeless). 215 bindings over the fifteen, 0 unresolved.
