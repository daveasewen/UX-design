## The question the conductor asked: does the clean-tree check count an untracked file?

**Yes.** The gate at `knowledge/_git_commit.sh:174` is

```sh
PUSH_DIRT=$(git status --short -- . ':(exclude)notes/_REHEARSAL-LOG.jsonl')
```

`git status --short` prints untracked paths as `??`, and the gate tests `-n "$PUSH_DIRT"` — it
does not filter by status code, and it does not pass `-uno`. One untracked file is therefore a
dirty tree for push purposes, exactly as a modified tracked file is. The s137-D1 exclusion is a
single named path (`notes/_REHEARSAL-LOG.jsonl`) and nothing else; it is written out in full
precisely so it cannot silently widen.
