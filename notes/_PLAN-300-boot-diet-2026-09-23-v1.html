The quiz

How we prove a shorter start is still enough.

The August Memento drill, extended by the adversary. A cut to the start is adopted only after it passes.

  1. Start cold: a fresh chat with only the shorter start, plus the fetch commands it names.
  2. Ask 24 things: the 18 facts, plus six “do something” probes — push the wrap commit; the build fails on a stuck lock; draft the demo brief?; tidy a log file; rebuild the deck; which reports exist for this session.
  3. Grade: right, right after a fetch, or “don’t know” all pass. A confident wrong answer fails.
  4. Pass bar: no confident wrong answers, at least 22 of 24 right, and fetching costs no more than the handoff it replaces (about 7K).
  5. August’s three measures ride along: it opens the right contract first time, every number it quotes reproduces, and the wrap certifies the session that actually ran.
  6. Three fresh chats pass before a card is adopted — and again after any change to how the card is made.

The answers are stored as fingerprints, so they never sit on disk in plain text.

Real tokens come only from the transcript’s usage fields: input + cache creation + cache read, per distinct message. The boot (126,185), the first reply (187,863), your first message (211,454) and the moment the helpers launched (250,519) are real.

Tape is a cl100k estimate of a recorded payload, scaled to real with two ratios solved from this transcript: tool descriptions ×0.983, prose ×1.453. The adversary re-derived prose at 1.40–1.45 from six helper boots and 1.43 from the second memory list.

Projected means measured parts added up, not a session that has run. The Friday-set figures remove measured items from measured totals. The Mac seat’s 30K is a bare core measured at 20.1K (Claude Code 2.1.280, print mode) plus sized additions: synced skills, the instruction file, three interactive tools; Artifact tool off.

The charts use one accent plus two greys. Colour-blind separation passes (ΔE ≥ 13) and every mark clears 3:1 on white; the greys fail the categorical colourfulness rule by design, as an emphasis palette.

How the levers were ranked

Score = saving × confidence × undo ÷ risk, then judgement. Confidence: 1 measured, 0.5 projected or weakened, 0.25 untested. Undo: 1 easy, 0.3 only from a copy. Risk: 1 low, 2 medium, 3 medium–high, 4 high. Two judgements on top: a Friday-set move ranks first among equals because it is cheap to try and to undo, and a project-scoped memory cut ranks above an account-wide pause because the pause’s cost falls on your client work. The order is an aid, not a measurement.
