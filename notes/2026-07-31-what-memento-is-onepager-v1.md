# What Memento is

An AI agent wakes up every morning with no memory of yesterday. Every session is the
first day on the job: the context is gone, the decisions are gone, the half-finished
thought is gone. Most teams solve this by pasting yesterday back in — more notes, more
documents, more context — until the agent spends its whole morning reading and still
starts work unsure what actually matters.

Memento is a different answer, named for the film. Leonard, who cannot form new
memories, does not survive by writing everything down. He survives by a system: tattoos
for the things that must never be wrong, Polaroids for the day's working notes, and a
hard-won discipline about whose handwriting to trust. The insight the film turns on is
that his real enemy was never forgetting. It was the confident false inscription — the
wrong thing written in permanent ink, read the next morning as truth.

Memento is that system, built for AI agents, and it does three jobs.

**It keeps the record.** What a session learns is written home before the session ends —
but layered by how firmly it is known. A passing idea, a standing observation, and a
settled decision are three different kinds of true, and the record keeps them apart, so
the next session inherits each at the weight it earned. Nothing gets flattened into one
undifferentiated pile of notes, and nothing ruled is ever quietly reworded.

**It prices the work.** An agent's attention span is finite and runs out mid-task if
nobody is counting. Under Memento, a session declares the cost of a job before starting
it — what it will spend to get oriented, to do the work, and to write the record home —
and steers by that declaration all day. It knows when a task is too large for the room
remaining, and when the right move is to hand a well-briefed piece of work to a helper
and verify what comes back, rather than push on and run dry a paragraph from the end.

**It orients its owner.** The third job is the one Leonard actually needed each morning:
not the archive, but the answer to *what do I have to do today?* Memento opens every
session with exactly that — what was decided last time, what changed overnight, what is
owed and in which order — so the day starts with direction instead of archaeology.

What makes it trustworthy is a rule borrowed from engineering rather than note-taking:
the record must be able to prove itself wrong. Every claim the system makes about its own
memory — that a summary is current, that a decision still stands, that a check really ran
— is tested by deliberately breaking things and confirming the alarm sounds. A memory
that cannot fail a test is not a memory; it is an assertion. Memento treats the confident
false inscription as the enemy it is, and spends most of its engineering there.

None of this was designed in the abstract. Memento has been built inside a live,
demanding project — a production design system — by an agent and a human working it
daily. Every rule in it exists because a session once went wrong without it. That is the
difference between a memory framework and a memory discipline: one is written first and
tested later; this one was tested first, and written down only when it survived.
