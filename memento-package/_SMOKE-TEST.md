# Smoke test — `machinery/_gen_chain.py` + the `_capture_gate.py` shim, standalone

**What this proves:** that the verbatim `_gen_chain.py` copy, running against the new
`_capture_gate.py` shim and nothing else from `knowledge/`, generates a chain, detects its own
staleness, passes its own selftest, and is running on the real tiktoken instrument rather than
the byte-divisor fallback. Run in a scratch fixture outside the repo, never inside `memento-package/`
or `knowledge/`.

`GOOD-MORNING.md` and `_LIVE-STATE.md` were hand-built from the exact section shapes
`_gen_chain.py`/`_capture_gate.py` parse — read off the code (`GM_VOCAB`, `LS_VOCAB`, the
`LATEST`/`PRIOR`/`DOFIRST` regexes, `LS_DELTA_RE`), not guessed and not copied from the real
`GOOD-MORNING.md`/`_LIVE-STATE.md` (whose content stayed untouched and unread-into this fixture).
Shapes used:

- GM: a `# Good morning, …` title, a blockquoted `> ## ★ LATEST — …` banner (2–4 fake bullet
  lines), a blockquoted `> ## ★ PRIOR — …` banner (must NOT survive into the chain), a
  `## ⬛ DO THIS FIRST` section with two `> **N. …**` items (to exercise the presence index), and
  `# §A Orientation` / `# §C Queue` sections padded with synthetic filler paragraphs (needed for
  one selftest bite — see the note below; the filler is nonsense placeholder text, not real

- LS: a `## 🛤 LANES` placeholder, a `## ⏱ LATEST DELTA — …` section (2 fake bullet lines), a
  `## ⏱ PRIOR DELTA — …` section (must NOT survive into the chain), and a `## LIVE` placeholder
  closing the DELTAS region.

## (d) `python3 machinery/_gen_chain.py --selftest`

First run (before the fixture was padded — recorded honestly, not smoothed over):

```
    ✗ is materially smaller than GOOD-MORNING.md (674 vs 902 tape, <40%)
  ✗ _gen_chain selftest: 1 bite(s) failed
EXIT=1
```

**Diagnosis, not a shim defect.** This bite (`out_tk < 0.40 * gm_tk`) asserts the generated chain
is materially smaller than the *whole* `GOOD-MORNING.md` it was cut from. `_gen_chain.py`'s
`BANNER`/`FOOTER` wrapper text is fixed-size boilerplate (~410–420 tape regardless of GM size);
the bite's 40% threshold only holds when GM itself is realistically sized (thousands of tape, as
in the real repo). My first-draft fixture GM was deliberately minimal (~900 tape total), so the
fixed wrapper alone blew past 40% of it — an artefact of fixture scale, not of `_gen_chain.py`,
the shim, or the parsing logic (every other bite, including the ones exercising the shim's own
`chain_parts`/`measure_tokens` output, passed on the first try). **Fix applied: enlarged the
fixture**, not the code — padded `GOOD-MORNING.md`'s §A/§C sections (outside the chain slice, so
the slice/wrapper numbers are unaffected) with ~30 paragraphs of synthetic filler text, pushing
whole-file GM to a realistic ~3,000 tape. Neither `_gen_chain.py` nor `_capture_gate.py` (shim or
original) was touched to reach this fix.
