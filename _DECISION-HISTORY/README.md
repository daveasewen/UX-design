## The rules

1. **Files land whole and are never edited after landing.** A correction gets a new dated file or a
   loud banner, never a silent rewrite — the Memento discipline applies here hardest.
2. **Both-way links.** Every file names its spine entry; every spine summary ends
   `History: _DECISION-HISTORY/<file>`.
3. **Narrative >10 lines goes here at write time**, in the same pass — the spine discipline that
   stops `_LIVE-STATE` regrowing (its header carries the same rule).
4. **RESURRECT tags.** Where Dave has flagged an experiment as future evaluation material, the file
   header carries `RESURRECT` naming what it might feed. `_FUTURE-STATE.md` holds the queryable
   register of these — the archive is the shelf, the future ledger is the catalogue.
