    One tab stop: Tab into the grid, then ← → ↑ ↓ move between cells (Home/End row ends, Ctrl+Home/End grid ends). Enter sorts a header, toggles a row checkbox, or opens the reference cell for editing (F2 also edits; Esc cancels, Enter saves). Type in the filter and press Enter to apply it as a removable chip. On a column header, Alt+↓ opens that column's filter and Alt+←/→ enters resize mode, where the arrows size the column (Shift for a bigger step) and Esc returns to the header.
