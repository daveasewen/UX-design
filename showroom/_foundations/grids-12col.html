The 12-column grid

A Foundations entry, not a component. The RULED layout tokens, live: 12 columns on web and 12 on app, with the margin and gutter each scale names. Every number on this page is read from knowledge/tokens/layout.json at build time — none is typed.

⛔ The grid below is CANON'S OWN. The overlay and the demonstration rows are .l-cols with .l-span-* children, under .cn-layout-utilities — the same utilities every gated snippet uses. No grid is re-drawn here, so what you are looking at is what a consumer gets.

⛔ The scale switch is a VIEW control. It changes which ruled pair of numbers the page is showing. Nothing on this page tunes a token, and there is no export block for that reason — there is no chosen combination to export. A token change is a ruling, and a ruling is Dave's.

What this page is, and is not

  • Nothing is re-drawn. The overlay is .l-cols and twelve .l-span-1 children; the demonstration rows are the same utility with the spans a consumer would write. A page-local grid would be a second grammar, and it would agree with canon right up until canon changed. The column wash paints behind the demonstration rows (s218-D6), so a card shows its own surface and the columns read in the gutters and the gaps.
  • ⛔ The collapse below breakpoint/ms is canon's, and it is real. Under 760px every .l-span-* goes full width — a media query in canon.css, written as a literal because a CSS query condition cannot consume a custom property. Narrow the window and the demonstration rows stack.
  • ⚠ Measured, and it is why these numbers are minted at build time: canon.css publishes --layout-app-margin, --layout-app-gutter, --layout-web-columns and --layout-app-columns, but the three WEB margin/gutter scales have no custom property of their own. There is nothing live to read, so the generator writes the store's values in as concrete instance dials (s200-D1) and the verification compares the rendered result against the STORE rather than against anything typed here.
  • No colour is authored. The column wash is the page's own single tint at 10% opacity over whatever ground the theme paints; every other surface, line and ink resolves through a canon token.
