How it works

Nothing on this page is a re-drawing. Every pane is the component’s own generated showroom page, loaded live.

01

Live pages, not pictures

Each pane loads the component’s generated showroom page, so its scripts run, its side-navs open and its tabs switch.

02

The header drives the pane

Theme, light/dark and width are broadcast to the pane as a URL fragment, so switching theme never reloads the component.

03

Two ways in

Type is the component ladder; Usage is the job the component does. Release phase filters inside both. Search with / or ⌘K; a machine-readable copy of this index is showroom/index.json.
