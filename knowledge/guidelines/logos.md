# Logos

The detailed logo standard (usage, structure, behaviours, placement, clear space, minimum sizes) lives on **create.hsbc** → [Logos](https://create.hsbc/foundations-and-identity/Logos.html). The Figma page provides the artwork sticker sheet.

## Logo set
Three logo lockups, each available in **Colour** and **Monotone**, and in **On Light** and **On Dark** treatments (the On-Dark artwork is the light/reverse version for dark surfaces):

1. **Hexagon** — the HSBC hexagon mark alone.
2. **Masterbrand** — hexagon + "HSBC" wordmark.
3. **Masterbrand with identifier** — masterbrand plus an "Example identifier" label (e.g. a business/division name) set in Univers Next Light.

That's **12 variants** (3 lockups × {Colour, Monotone} × {On Light, On Dark}).

## Exported assets
SVGs exported to `knowledge/assets/logos/<lockup>-<light|dark>-<colour|mono>.svg` via `_export-logos.py` (Figma `file_content:read` token). All 12 came through as **vector** (hexagon in `#DB0011`/white; masterbrand wordmark and identifier as vector paths) — no embedded raster.

> Per the icons sourcing rule, treat these exports as **internal prototype assets**; for production/dev handoff, source official logo artwork from create.hsbc / the UI Centre.
