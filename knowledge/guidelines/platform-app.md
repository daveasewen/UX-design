# Platform — App (mobile)

> Source: create.hsbc — `platforms-and-channels/app.html`. Captured 2026-06-18 for RAG. Summarised. Landing/pointer page; deeper detail on the sub-pages below.

## Purpose

Guidelines to **design and build consistent, HSBC-branded app experiences** across mobile devices.

## Structure

- **App foundations** — how the **type scale, dark mode, and elevation** are applied specifically to the app experience. (These are the same foundations captured in `tokens/typography.json`, `guidelines/dark-mode.md`, `guidelines/elevation.md` — the app page is the channel-specific application of them.)
- **Design toolkits** — the **building blocks** for accessible, on-brand app design. This is the channel home of the **HSBC Common Toolkit** Figma library (the component set already ingested into `knowledge/components/`), including the app-only components (bottom/top nav bars, Quick actions, Status indicator (mobile app), Partial modal/Drawer, etc.).
- **Legacy standards** — design standards for legacy platforms.

## How this maps to the system

- Confirms the **app-only** scoping already recorded on several component metas (nav bars, quick actions, status indicator, partial modal).
- Anchors app design to the shared foundations (type scale / dark mode / elevation) rather than a separate system — consistent with our single token store.
- Accessibility for app follows the same **WCAG 2.2 AA** bar (see `digital-accessibility-standards.md`).
