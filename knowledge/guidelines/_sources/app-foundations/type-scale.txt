App type scale

Our type system adapts across devices to best display content and promote a clear hierarchical standard across the HSBC estate.

Sections: Usage · Scale · Titles

Usage

Use our brand font, Univers Next for HSBC, whenever possible. Use different font weights to create hierarchy in our designs.

Scale

The default scale is comprised of seven sizes and is anchored around a 16px baseline (1.000em).

The three smaller text sizes are generally for standard text (eg body copy, links and other UI), and the four larger sizes are used for titles, section headers and sub headers.

S 1 — Font size 33px (2.063em) · Leading 40px (1.15em) · Paragraph 20px (1.250em)
S 2 — Font size 28px (1.750em) · Leading 36px (1.2em) · Paragraph 18px (1.125em)
S 3 — Font size 23px (1.438em) · Leading 30px (1.3em) · Paragraph 15px (0.938em [sic — unclosed paren in source]
S 4 — Font size 19px (1.188em) · Leading 27px (1.4em) · Paragraph 14px (0.875em)
S 5 Baseline font size — Font size 16px (1.000em) · Leading 24px (1.5em) · Paragraph 12px (0.750em)
S 6 — Font size 14px (0.875em) · Leading 20px (1.4em) · Paragraph 10px (0.625em)
S 7 — Font size 12px (0.750em) · Leading 16px (1.3em) · Paragraph 8px (0.500em)

Accessibility

iOS - Use Dynamic Type and test that your app's layout adapts to all accessibility font sizes, including the largest.

Titles, section headers and subtitles

Titles, section headers and subtitles use sizes S4 and above.

Page titles and subtitles use light and regular font weight.

Different subtitle sizes can help divide up sections of text.
