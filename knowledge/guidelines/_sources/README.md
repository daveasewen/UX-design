# _sources — raw capture snapshots for ingested guidelines

One folder per ingested standard. Each file = the page text as captured (site chrome
stripped, source typos preserved with [sic], capture gaps noted in the header). Purpose:
**audit trail** — review what was captured against what was encoded in the guideline
file, without needing portal access. These are snapshots, not living documents; the
encoded `guidelines/*.md` file is the operative artifact and the register tracks its
[REVIEW] items.

Convention started 2026-07-02 (web-foundations). Earlier ingests (colour-2026,
illustration, icons, pictograms, motion, typography ×2, generative-AI) predate it —
their capture provenance lives in their file headers only; backfill only if a
reconciliation dispute needs the raw text.
