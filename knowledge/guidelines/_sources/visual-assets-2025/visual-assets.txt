Visual assets
The term ‘visual asset’ describes the many different media elements (eg video, photography and illustration) in our design system. This standard concentrates on the context and application of visual assets, rather than their creation.

Usage
When deciding whether to include visual assets in a design, think primarily of how they’ll benefit the user experience. Ask yourself the following questions:
what’s the intent and purpose of including visual assets?
will they help the user better understand the content or objectives?
will including visual assets distract, obscure or slow the user’s progress at all?
For responsive design, you should also consider the impact on mobile and desktop experiences.
If you don’t have contextually-relevant visual assets to support the content theme, avoid using images for the sake of layout or design. Unsuitable assets can harm the user experience and weaken our visual communication – sometimes less is more.

Attributes
The content or attributes of visual assets are categorised as either ‘complementary’, ‘informational’ or ‘functional’. These attributes are defined by the nature of content, rather than the type of visual asset. Whatever the content nature, it’s important that all visual assets are relevant to the content context.
Functional
This type of imagery is used for user interface elements at a more macro-level. They can represent actions, states or categories of information. The types of visual assets considered to be functional include icons, avatars and logos.
Informational
This type of imagery illuminates specific points and take-outs, or features and benefits to the user. It is therefore considered to have a higher informational value for the user. The types of visual assets used would include product photos, infographics, diagrams and charts.
Complementary
We use complementary to visually tell our brand story, creating a confident and consistent brand. This type of imagery supports the general theme and the flow of the content. It complements the content rather than speaking for it. The types of visual assets used include photography and illustration.

When to use complementary assets
Visual assets play an important role in connecting our brand promise with the online user experience. The level of visual engagement depends on the type of page, its purpose and position in the overall user journey.
High visual engagement
Areas that are considered to be highly visually engaging include the home, hub, landing and promotion pages. Complementary assets can be used throughout the content of these pages.
Medium visual engagement
Product, service and article pages have less visual engagement because the user needs to focus more on the detail and information. Complementary imagery can still be used, but should be kept to a minimum – normally within the header or at the start of a long section of content. Informational and functional assets are more important to the user at this level.
Low visual engagement
Applications and processes have low visual engagement because they’re primarily focused on guiding or helping the user through their task. These pages should only use visual assets that are fundamental to supporting the user experience, to avoid any distractions. Informational and functional assets can be used where directly appropriate. If complementary assets are to be included at all, they should be at the very start or completion of the application or process.
Onboarding scenarios
For users new to HSBC, onboarding may use more complementary assets if they directly enhance the user experience – they shouldn’t distract from the central purpose.
For existing customers, the introduction of new features should be more focused, using informational and functional assets to help the user complete the onboarding as quickly and easily as possible.

Visual user experience
A consistent visual approach builds familiarity for our users, which leads to greater understanding and trust.
Platform and familiarity
Users interact with our products through many different touchpoints. Adopting the same approach to visual assets across multiple platforms ensures that our products feel instantly familiar and connected.
User journeys and experience
Consider the use of visual assets in the context of end-to-end user journeys, rather than just within a specific section of an app or website. For example, having a different approach to visual assets for the logged on and logged off experience can be disorientating.
Patterns and expectations
Use the same types of visual assets with the same types of patterns and interactions. For example, if you’re using an illustration to support the key message for a confirmation page, use an illustration for all similar instances. This makes it easier for users to recognise and understand patterns.
Areas where consistent asset types and placements are particularly important include:
applications
onboarding
coach marks
tutorials
alerts messaging
status codes (eg error 404)
empty states.
Hierarchy
If you’re using multiple visual assets on a page, you need to consider how they work together in the context of the user experience. Avoid conflicts of attention that can create unnecessary noise. Visual assets that support a primary goal should have more emphasis than those supporting secondary goals or the content theme. This can be achieved by using hierarchy, order, scale, space, contrast and balance.
Re-using visual assets
Visual assets should be only be re-used in the same context, metaphor or purpose to avoid confusing users and losing the effectiveness of our visual communications. For instance, one thumbnail image that appears twice and links to two different pieces of content is completely disorientating – as is using the same hero image for different articles, products or services.
Don’t use the same visual asset to navigate to, or to represent different articles, products and services.
Don’t use visual assets out of their functional context. The memo icon in this card is out of context in terms of representing the content theme of fraud.

Types
Below is a brief decription of our visual assets.
Animation
In this context, animation assets are graphically created dynamic content within a placement, rather than the motion applied to user interface elements. Animations are usually delivered within a video format, but can also be generated by using code within the page.
Photography
Photography is predominantly used to communicate our brand promise, but it can also include the use of product imagery, retail spaces and screenshots.
To find out more about the guidance and creation for these assets, see our photography guidelines.
Illustration
Illustration can be used on its own or incorporated into other media types, including video, infographics and charts.
Read our illustration guidelines to find out more about the guidance and creation of illustration assets.
Infographics
Infographics are the visual representation of a story. They can include a combination of imagery, data, and text to help the user quickly and easily understand a narrative.
See our illustration guidelines if including these assets within an infographic.
Charts
Charts are the graphical representation of the measurement of relational data with variable quantities. These provide a visual way for the user to see and understand results, trends and patterns in data. Familiarise yourself with our data visualisation standards and data visualisation colour palette standards.
Diagrams
Diagrams visually demonstrate how something might work or behave in a schematic representation.
Avatars
Avatars are an on-screen visual representation of a user’s identity. Avatars can be found in text messaging applications and user account profiles.
Icons
Icons can be used to symbolise information, represent calls-to-action or draw attention to status changes.
To find out more about the guidance and creation for these assets, read our icon guidelines.
Favicons
A favicon is an image that represents a website. They’re typically found in browser address bars, but can also be used to indicate a favourite link or shortcut to a website.
Find out more about their guidance and creation in our favicon guidelines.
Logos
Logo visual assets are the graphic representation of third party companies or services.
For specific guidance on using HSBC logos, read our logo guidelines.

Behaviour
Visual assets need to adapt to different screens and layouts. Always test visual assets across a representative range of devices to ensure they’re displayed correctly.
Photography
Photography can be cropped into different standard ratios to work with changing layouts and screen sizes.
Illustrations
Illustrations may need to be reformatted, and line weights adjusted, for different layouts and screen sizes. Be mindful of the different placements when creating illustrations.

Content Display
Point of focus
By choosing simpler or more focused imagery, we can present clearer concepts. This allows the user to understand and scan the content more quickly. Point of focus can also be achieved by using colour, contrast and density within visual assets. Find out more in our photography and illustration guidelines.
Light and dark modes
You need to consider how visual assets are displayed in both light and dark modes (if using both modes), as it can have a profound effect on design and user perception. For instance, assets that bleed into the background colour they sit on in light mode, might appear enclosed or gain more / less prominence than intended in dark mode. You may need to export different versions of the same asset to optimise the design for both modes.
Icons, and some logos, have a transparent background. If an icon is black in light mode, the colour values will need to be reversed so that they display correctly in dark mode. Some of these changes can be done at a code level.
Quality Matters
Always use sharp, high quality visual assets. Users associate the quality of imagery with the quality of the product or brand. Visual assets should be optimised and tested for our supported devices, including both low and high definition screens.
If you don’t have the quality of assets required, it’s better not to use any visual assets at all rather than risk creating a bad impression of the product or brand.

Placements
Visual assets can be used in various positions within a layout. Here are the most common terms for these placements.
Hero
The hero placement is normally the first large visual element before the main body of content starts, often before or in conjunction with the page title. Heroes reflect the overall content theme of the page.
The type of imagery is normally complementary, but informational assets can be used if appropriate.
Display
More visually prominent than the standard spot placement particularly on wider viewports. The display placement can be used to represent complete sections of content.
The type of imagery used can be complementary or informational.
Spot
This type of imagery is used for user interface elements at a more macro-level. They can represent actions, states or categories of information. The types of visual assets considered to be functional include icons, avatars and spot placements are used to highlight features or information from within a section of content.
The type of imagery used can be complementary but informational assets at this level offer more value to the users.
Thumbnail
Thumbnail placements are used to preview and link to content, or to identify and categorise list items.
The type of imagery used can be complementary, informational or functional.
Interface
Interface placements appear at a more macro-level. These placements are typically used for icons, avatars and logos. They are never complementary in nature.

Ratio
Using common aspect ratios streamlines the production of visual assets. These standardised ratios make visual assets more portable and able to be used in other layouts and templates. In some instances where bespoke ratios are required, it’s possible to use code to crop the standard visual assets in-page.
Digital aspect ratios state the width first, then the height. So 4:3 is landscape, and 3:4 is portrait in the digital space.
Video
The most common format for video is 16:9. This format works well across all screen sizes including full screen. Other ratios that can be used include 21:9, 4:3 and 1:1, but these may not be suitable for full screen viewing. Depending on placement within the layout, and options to view content full screen, more than one ratio may be needed.
16:9 standard
Animation
The guidance for video ratios also applies to animations.
16:9 standard
Photography, illustration and infographics
These media types share similar ratios to allow assets to be interchanged.
21:9, 16:9, 4:3, 1:1 are standard formats
These ratios can be reversed if portrait assets are required
Icons and avatars
These assets are typically square. Icons and avatars that appear rounded are likely to have masked the square asset using code.
1:1 standard
Logos
Third party logos are dynamically interchanged, so the ratio is based on accommodating the worst case scenarios for vertical and horizontal formatting. Although 1:1 is logically the best format to accommodate both landscape and horizontal logos, it can take up a lot of space, so landscape ratios often work better.
16:9, 4:3 standard
