Toast

molecule

Fire a transient message — it slides up, stacks bottom-up, counts down a hairline and auto-dismisses in ~4s. Hover to pause the timer; close cancels it. Errors announce assertively.

Neutral uses the near-black base surface; status toasts carry a RAG tint, a status badge and an ink message — colour never sits on the text alone.

Alert / Callout

molecule

Persistent inline messages. Expand the declined-transfers callout for detail, dismiss any of them, then Reset. On warnings the amber lives on the icon and accent bar only — the text stays ink so it always reads.

Date picker

organism

Click the field or the calendar button to open the month grid. Today carries a ring, the selected day fills near-black, past dates are disabled. Keyboard: arrows move, Enter selects, PageUp/PageDown change month, Esc closes.

Month
Today: 14 Jul 2026

Past dates can’t be selected as a value date. Selecting a day fills the field (e.g. “14 Jul 2026”) and closes the calendar.

Date range

organism

A Material-style range variant: two scrollable months. Click a start day, then an end day — the endpoints fill solid, the days between them get a soft tint band. Arrows move focus, Enter sets start then end, Esc closes.

Month Month
Range set: 12 Jul – 18 Jul 2026

Click a start day then an end day to set the range. Unlike the value date above, past days stay selectable — this sets a reporting period, not a forward-dated payment. Narrow the frame to see it collapse to one month.

File upload

organism

Drop files on the dashed zone or activate it to Browse. Each row shows a type icon, size and a determinate progress bar that fills to a success tick. One row is in an error state — press Retry. Remove any row with ×.
