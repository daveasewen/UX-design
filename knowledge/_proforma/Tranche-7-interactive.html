Mega menu

organism

Three variants of the same organism — a NavToggle opening a wide panel of grouped links (headings + lists, not role="menu"). Esc closes and returns focus; there is no focus trap — it's navigation, not a dialog. Each is shown open below. The featured variant mirrors the CDC “content-heavy services” pattern: a masthead (brand + person + hamburger) that reveals an exposed L1 row, four groups of links, and a divided Journeys rail — with the red active underline swapped for a mono ink bar.

Drawer & NavAccordion

organism / molecule

The generalised T1 Drawer — edge-left|edge-right|edge-top|edge-bottom + modal. This modal instance is a real dialog: role="dialog" + aria-modal="true", a genuine focus trap, Esc-close, focus returns to the opener, and the background is made inert while open. It's the same drawer the header hamburger (section B, narrow) and the side nav's narrowest state (section C) open — one component, three doors in.

Inside: a .navacc — nested disclosure rows that expand their child link group in place (aria-expanded per level). It carries the same content as the Side nav (section C) — the burger is that navigation's mobile form.
