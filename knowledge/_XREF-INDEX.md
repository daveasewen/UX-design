## How to traverse

- **Component → everything:** `_XREF-INDEX.json` `components["Modals"]` → its tokens, SCs, guideline docs, anti-patterns, deprecated bindings in one read.
- **Token → sibling components (blast):** `tokens/_blast-radius.json` `ranking` (or `by_component` reverse).
- **SC → sibling components:** `compliance/graph-index.json` `by_sc`.
- **Migration coupling:** components sharing a `god_nodes_touched` entry move together — rebind/test them as a set.

> `god_nodes_touched` lists only the high-blast tokens (blast≥7) a component binds — the ones whose change ripples widely. Full token list per component is in the JSON.
