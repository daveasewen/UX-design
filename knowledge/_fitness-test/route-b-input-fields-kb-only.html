Gap log — what came from the KB vs what I invented
✅ Off-the-shelf from the KB (the generalisation win)
  • Focus ring — pulled focus/ring + layout/focus/ring-width|offset straight from the new GLOBAL standard (#2). For Tabs I had to invent this; here it was off the shelf.
  • All state colours — text, border, background, error resolved cleanly per token in both modes.
  • Type — font-5 size/line-height; font-weight/medium now numeric (500) thanks to #5; font-family fallback stack used.
🟡 Still invented (adoption not done on this meta)
  • All geometry — field height (48), padding, label gap, underline thickness (1/2px). The meta has no dimensions block, so every size is a guess. (Schema slot exists; just not populated for Input fields.)
  • Underline-style assumption (bottom stroke) inferred from the "bottom stroke" effect language, not a structured token.
🔴 KB defect the build makes visible
  • Dark mode is broken. Every form/* token resolves to #FFFFFF in dark, and form/background/default flips from transparent (#FFFFFF00) to opaque white — so the field becomes a solid white box. With text/default dark = #FFFFFF, the typed value is white-on-white (invisible). Same defect class as Tabs' original tabs/*; form/* is the next reconciliation target.
  • The contrast gate would not catch this — it audits text/icon/indicator tokens, not */background or */border surfaces. Coverage gap to close.
