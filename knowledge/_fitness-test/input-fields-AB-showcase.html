What the side-by-side shows

  • Focus generalised. Route B's focus ring is the new focus/ring standard pulled straight off the shelf — no invention, unlike Tabs. The systemic fix paid off on a second component.
  • Geometry didn't. Every Route B size (height, padding, underline) is still a guess — Input fields' meta has no dimensions block. The schema slot exists; the data doesn't. Next: a per-component adoption pass.
  • Dark mode is broken. All form/* tokens resolve to #FFFFFF in dark, and form/background/default loses its alpha (transparent → opaque white), so the field is a white box with invisible white text. form/* is the next reconciliation target — and the contrast gate is currently blind to surface/border tokens, so it wouldn't catch this.
