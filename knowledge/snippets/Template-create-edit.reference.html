    Edit — the same template, four differences

    (1) The fields arrive PREFILLED. (2) An unsaved-changes strip appears on first edit — ink and a rule, never a RAG hue: the word "Unsaved" carries the meaning. (3) The action bar gains a DESTRUCTIVE action, pushed to the far edge so it is never adjacent to Save. (4) The sort code is LOCKED, because changing where money goes is a different, verified journey — not a field edit. Type in Nickname to see the strip appear.
