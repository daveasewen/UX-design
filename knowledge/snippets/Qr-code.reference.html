1 — The default

A real, scannable symbol. It encodes exactly the string printed beneath it, and the same destination is repeated as a working link, because a QR code on its own only serves someone who can see it and has a second device to hand.

2 — Sizes

The size of a QR code is the size of one module, not the size of the box. Small is 4px per module, medium 8px, large 12px. The same symbol, the same quiet zone, three module sizes. Anything below roughly 4px per module on screen starts failing on ordinary phone cameras at a normal reading distance — the small specimen is drawn at that edge on purpose.

3 — The quiet zone

The four-module margin lives INSIDE the SVG viewBox, so it travels with the symbol and cannot be cropped away by a container that tightens its padding. The dashed rule below is demo chrome marking where the symbol proper begins; it is not drawn in the component.

4 — What happens in dark mode

Two answers, both drawn. Toggle the page theme and watch the pair: the left symbol does not move, because it binds tokens whose value is the same in both modes. The right one inverts, because it binds the page's own text and background. Neither is ruled.

5 — A longer payload is a denser symbol

More content means more modules in the same square, so at a fixed pixel width each module gets smaller. Both symbols below are drawn at 8px per module, and the longer payload is therefore physically bigger — that is the right behaviour. Fixing the outer box instead, and letting the modules shrink, is how a QR code silently stops working.
