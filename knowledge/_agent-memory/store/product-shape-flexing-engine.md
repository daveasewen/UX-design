RULED 2026-07-03 — **ADR-0006** (docs/decisions/), extends ADR-0005 + the [[critical-review-2026-07-02]] scoreboard.

Dave re-examined "designer-in-a-box engine vs multidisciplinary agent setup" (the archived harness) before committing further. Desk research RECOVERED not re-run (`docs/research-dossier.md` 2026-05-31, ADR-0001 — they already voted for the engine). Verdict: **engine-first is low-regret** — (a) necessary-vs-optional: any generator's output still needs the gates, so the engine is needed in both worlds, the orchestrator in only one; (b) reversibility: add specialist agents ON TOP later, cheap — orchestrator-first is expensive/commoditising and still needs the engine; (c) market: orchestration commoditising, enforcement-at-generation unoccupied; (d) empirical: harness 1 dry-run+died vs engine 53/54 commits + GOV.UK generalisation. The two are different LAYERS, not competitors — own governance (the standard) beats owning generation (the labour). Disciplines survive as criteria packs, not agent pipelines.

**Product shape = a FLEXING engine.** Four dials: discovery-depth (none/quiz/full) · register (cool→warm→hot) · unit (cluster→screen→journey) · library-growth (retrieve else generate→gate→promote). **Two named modes** matching Dave's real bimodal org: **FLOOR/churn/"vibe"** (low discovery, sober, BA-instruction→compliant screen = "standards-compliant Figma Make" = THE WEDGE; attacks quality-variance by raising the floor; provable NOW on the built engine) and **CEILING/novel/"analysis"** (full discovery, register spread, journey, iteration; depends on unbuilt G1/G5). Same curbs at every setting = what makes the flex safe.

**Library reframe (compounding canon):** don't chase a "complete" library (treadmill) — the labour is inventing novel-to-us CLUSTERS, so apply the promote loop to clusters → each lock-up becomes gated canon once (judgment-spent-once on composition). Cluster-promote is the LEAST-proven part (only tokens/motion promoted so far); proving it > N hand-built components. The ease Dave noticed ("I could build the library with Claude in spare time") IS the thesis — labour moved from making to judging.

**Why:** the whole value is variance-reduction — encode senior judgment once, apply it uniformly across a team of mixed designer/research quality. See [[fixed-flex-charter]], [[pipeline-mental-model]], [[promenaut-product-vision]].

**How to apply:** build FLOOR/built capability first; scope clusters/canon to a real journey's demand (extends review D3); don't re-litigate architecture without new evidence — the real test (D2) is the arbiter. **D2 SHAPING 2026-07-03:** first live test = a scoped NOVEL-SCREEN proof (two colleagues engaged; ceiling track; THEY own discovery; engine bounded to generate→enforce→compose→register→promote on ONE screen; success + comparison baseline agreed up front) — see `_TEST-PLAN-novel-screen-proof.md`.
