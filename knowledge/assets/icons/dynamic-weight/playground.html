Dynamic-weight icons

Outline icons whose line thickness, colour and scale are each a single variable. Drag the thickness slider for full control, or snap it to a font weight so the icon reads as a member of the type family next to its label. Built as outlines because the HSBC catalogue is filled and can't be re-weighted.

Controls

On: thickness stays the px value above at any size (system-consistent). Off: line scales with the icon.
