# Prompt 1 — Kickoff / orient the agent

Paste this into a fresh agent session opened in the repo folder.

---

You are joining an existing, planned project. Do not start building yet.

First, read these files in order and then summarise your understanding back to me:

1. `AGENTS.md` (root) — your operating manual.
2. `docs/research-dossier.md` — the research and the reasoning behind every decision.
3. `docs/architecture.md` — the two-layer architecture.
4. `disciplines/ui-design/pipeline.md` and `disciplines/ui-design/spokes.md` — the working pipeline you'll run.

Then tell me, in a few sentences:

- What this project is and the two layers it's built on.
- Which pipeline is "working" vs "skeleton", and what the working pipeline's steps are.
- The non-negotiable rules for UI generation (there are five in the local AGENTS.md).
- The compliance bar and how the WCAG version is set.
- Where the knowledge layer lives and what still needs ingesting on this machine.

Do not change any files in this step. Once your summary is correct, I'll tell you
the next stage. If anything in the repo looks inconsistent or unclear, flag it now.
