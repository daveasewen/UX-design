Dave's reframe: the old register bands were **LEADING** — they prescribed the output (dark band / hero / gradient), not the dial, so a "pass" only proved instruction-following, and one screen got reskinned 3 ways (that's why the first test run's variants looked so similar — mostly a definition problem, plus anchoring).

**Register = level of INFERENCE, realised as a ramp that lifts curbs to a floor that never moves.** Two coupled dials: inference (sober OFF/retrieve → balanced BOUNDED/extend, must still read HSBC → expressive MAX/invent) + curb set (sober & balanced hold cardinal+foundational; expressive holds **cardinal ONLY**). "Sober" = don't infer, NOT "boring". Maps to tiers: sober≈T1, balanced≈T2, expressive≈T3-but-within-cardinals (the leash old T3 lacked). Unifies register with retrieval-not-recall (§5): the cardinal floor is retrieved, so craft runs hot but can't drift off-brand.

**Ranked curbs:** CARDINAL (never lift, any register) = brand colour, type, radius/angle (square), logo, **a11y floor + safety patterns** (regulatory — Dave didn't name these but they're cardinal), data-chart-flat carve-out. FOUNDATIONAL (held sober&balanced, released at expressive) = flatness/elevation, composition/layout, density, motion amount, red-forwardness, new-component invention. Everything else = road (flex).

**Two NEW mechanism pieces — named-not-built (new gaps):** (1) ISOLATED GENERATION — each band a cold pass from the same signed contract, none seeing the others (kills anchoring / "pollution"; the isolated-subagent pattern from `docs/research-dossier.md`). (2) DIVERGENCE PROBE — measure how far apart the 3 bands actually are, flag if they cluster; advisory→earns blocking; threshold is **screen-relative** (cardinal-heavy screens like payments have a narrow road → legitimately similar, NOT a failed spread — so don't over-read sameness, and pick test screens with latitude).

**Why:** a register that describes looks bakes the answer into the brief and tests instruction-following, not judgment; an inference ramp tests judgment and makes *expressive* a retrieval-not-recall stress test (max licence — do the cardinals still hold?).
**How to apply:** de-lead any register input (set the inference level, not the look); build isolated-gen + divergence-probe as the register machinery Dave asked to embed; the novel-screen test ([[product-shape-flexing-engine]] / `_TEST-PLAN-novel-screen-proof.md`) uses this and picks a screen with compositional latitude. Names kept (sober/balanced/expressive); retrieve/extend/invent = the gloss; full rename deferred (blast radius).
