RULED 2026-07-04 (Dave) → charter §9a. Emerged from the D-1 gestalt-boundary decision on the provenance task ([[register-inference-ramp]]): instead of picking one human/model line, Dave saw the two options as **two working modes** and said "maybe it should be built into the harness."

**The two modes (a candidate first-class harness dial, named-not-built):**
- **Converge / ship mode = Option B (ADOPTED).** An **advisory brand self-check** runs the six design principles (`brand-principles.md`) as a RETRIEVED checklist, surfaced as a pre-flight card — NOT a gate, carries the contrast-gate humility label ("checks passed ≠ feels HSBC", [[gate-blindspot-state-contrast]]). Fast; the **floor/churn** end (BA-instruction → compliant screen).
- **Explore / noodle mode = Option A (OPEN, not rejected).** No automated verdict; open human judgment / dossier-style deliberation. The **ceiling/novel** end where sitting with it is the point.

**Why it matters:** maps exactly onto the flexing engine's two ends ([[product-shape-flexing-engine]], ADR-0006 floor vs ceiling). So mode isn't a per-task choice — it's a **dial**, like register. The residual whole-screen gestalt is out-of-model (gestalt = where LLM-as-judge fails); the mode decides how the human is brought in, not whether.

**AUDIT 2026-07-05 (Tier A batch 3): DEFER (kept Tier A).** Abstract/named-not-built; inherits §9a (framing vouched, proven deferred). **Dave's reflections (carry into the exploration):** harness must be **flexible to a degree** — modes might be a **clean switch OR both** (simple toggle + an **advanced mode** to tune); maybe even a **"let it rip" mode** for fun; **finding the use cases is the important part**; **research + iterate, start small, expand if needed**; the **dials may need exploration, and that exploration may define the settings/toggle**. Own research thread (task created 07-05), not the audit.

**How to apply:** when building the harness, treat MODE as a first-class input alongside register. Ship-mode wires the advisory self-check; noodle-mode leaves gestalt fully human (candidate home for the REVIEW-DOSSIER instrument as the deliberation surface, [[process-doc-language-review]]). Don't build the self-check as a blocking gate — advisory only, earns blocking by bite-test. Related: [[register-inference-ramp]], [[fixed-flex-charter]], [[generation-mechanism-ideas]].
