Dave saved a Swiss / International Style design system and asked to use it for "our documents going forward." The full spec lives at `/Users/daviewen/Documents/Claude/Projects/digital-experience-transformation/Swiss-design.md`.

**Why:** Dave wants visual/HTML deliverables (brochure pages, research-document profiles, decks, web layouts) to follow a consistent typography-led Swiss grid idiom rather than ad-hoc styling.

**How to apply:** For any HTML page, brochure, research document, or web layout on this project, follow `Swiss-design.md` — typography-led (weight/scale/tracking carry the layout), a single accent colour used sparingly (never as a fill), 8px spacing system, full-width 1px hairline rules between sections, the label / proposition / dimension grid patterns, and WCAG 2.1 AA. Two archetypes: A = brochure hero page, B = research-document profile. Swap accent + font per project; keep the structural rules.
